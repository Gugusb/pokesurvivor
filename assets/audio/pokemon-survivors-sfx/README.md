# Pokémon Survivors SFX Pack

音效设计与提供：Gugusb。按提供的原始 WAV 文件接入；未重采样、变调或修改素材。原项目其他素材的许可证和署名保持不变。

- skills/{kind}_cast.wav：实际技能释放时播放。
- skills/{kind}_hit.wav：命中、地雷爆炸/陨石落地时播放；buff_hit 表示增幅成功施加。
- kills/kill_normal.wav、kill_elite.wav、kill_boss.wav：普通、精英、BOSS 击杀。
- 15 种原始技能类型各自配对，不依统一后的职业标签合并音效。

实现位于 js/core/audio.js。首次交互后以 4 路并发预加载 33 个文件（671762 字节，PCM16/mono/44100Hz），解码结果复用；加载失败暂用原合成音，10 秒后可重试，不补播过期攻击。实际技能/击杀按类别限频，最多 18 个采样声部、同一文件最多 3 个，命中与击杀优先于释放。采样速率固定 1，游戏倍速不改变音高或音长。归一音量：释放 0.28、命中 0.34、普通击杀 0.40、精英 0.46、BOSS 0.50，接入原音效音量、静音及压缩器。

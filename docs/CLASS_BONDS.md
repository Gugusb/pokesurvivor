# 远征职业羁绊：v0.43.0-alpha.20

只作用于上阵队员的对应技能，队长参与人数但不受益。人数按不同宝可梦名称去重；同一宝可梦的多个同职业技能只贡献一次。候补不计数，倒下的上阵成员沿用原规则保留计数。Z招式不接受职业效果。

|职业|原技能类型|3人效果|6人追加效果|
|---|---|---|---|
|投射物|projectile / boomerang / cone|结算敏捷、耐力+50/100/150%|每消耗一次穿透，后续伤害、碰撞半径、绘制尺寸乘1.2；不弹射|
|近战|melee / dash|溅射范围+50/100/150%|180范围内每名活敌增加10%敏捷、2%实际伤害吸血，最多10名|
|能量柱|beam|沿用原范围成长|沿用PP持续引导|
|连锁|chain|沿用跳跃次数成长|沿用延迟连锁、短暂停顿和敏捷加成|
|区域打击|meteor / trail|结算敏捷、耐力+80/150/250%|前摇延长、技能范围逐渐增至3倍，落点分布范围2倍|
|绽放|nova / aura|伤害+20/100/150%|范围+200%，每次有效命中25%概率眩晕1秒|
|环绕|orbit|半径+100%，伤害+50/100/150%|420范围锁敌，发射追踪环绕物，造成强化后原伤害3倍|
|召唤|mine / turret|持续时间+50/100/150%，数量上限+100/200/300%|炮台锁定目标+2、射速3倍、伤害+20/50/100%；地雷范围3倍、伤害+100/200/300%、必定眩晕2秒|
|增幅|buff|不激活|不激活|

表中三个数值依次对应0、200、500层，节点之间线性插值；500层以上按200—500段斜率的一半继续增长。保留既有每个羁绊10000层的存储上限。职业初始层数为0，人数达到门槛即获得基础效果。属性羁绊和蛋组规则保持各自口径。

## 首轮试玩参数

参数集中在 `config/economy_config.json.classBonds`，便于后续调数值。

- 近战敌群收益上限：100%敏捷、20%实际伤害吸血。位移增加碰撞宽度，不延长冲刺距离。
- 陨石前摇从0.5秒变成1秒，预警期间半径从原值增至3倍；索敌/无目标落点范围2倍。地面轨迹先预警1秒，随后保留原有持续时间，并在此期间半径增至3倍；随机落点位于自身技能半径2倍范围内，只选择可用地面。
- 绽放的冲击波通过投射尺寸和径向速度3倍扩大覆盖范围，光环直接使用3倍半径。
- 环绕发射速度420，追踪系数10，飞行最多1.5秒；命中、撞墙或超时后等待1.2秒补充。每个环绕位置独立计时，仍需正常消耗PP维持技能；停止维持会清除正在飞行的环绕物。
- 炮台额外目标选择不同敌人，敌人不足时按实际数量发射，不对同一个目标重复补发。召唤数量提升作用于场上存量上限，保留单次施放数量。每名队员每招式同一施放通道最多128个召唤物，防止高层数无限堆积；持续时间和伤害仍按层数成长。
- 所有普通、精英和BOSS均可眩晕，BOSS持续时间减半。眩晕冻结移动、接触攻击、技能推进，已有场景投射物/范围危险和持续伤害继续结算。
- 穿透成长在有效命中结算后发生，不反向提高本次伤害。草丛不消耗穿透，因此不成长；实体可破坏物消耗穿透并触发成长。回旋保留返程行为，扇形保留原投射方式，不添加随机弹射、爆炸或额外暴击。
- 二级羁绊使用带高光的独立职业配色，伤害元素不变。职业直接增伤分账为对应“xx羁绊伤害”；攻速、范围、控制、吸血收益不伪造额外伤害。

职业标签同步用于编队、商店/战利品介绍、特性叠层与终端燃料、突破材料、野外匹配和后台DPS队伍快照。快照保留原物理 `kind` 并新增统一 `class`，旧历史记录不回写。

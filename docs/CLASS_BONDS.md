# 远征职业羁绊：v0.43.0-alpha.25

只作用于上阵队员的对应技能，队长参与人数但不受益。人数按不同宝可梦名称去重；同一宝可梦的多个同职业技能只贡献一次。候补不计数，倒下的上阵成员沿用原规则保留计数。Z招式不接受职业效果。

|职业|原技能类型|3人效果|6人追加效果|
|---|---|---|---|
|投射物|projectile / boomerang / cone|结算敏捷、耐力+50/100/150%|每消耗一次穿透，后续伤害、碰撞半径、绘制尺寸乘1.2；尺寸受下述安全上限约束，不弹射|
|近战|melee / dash|溅射范围+50/100/150%|180范围内每名活敌增加10%敏捷、2%实际伤害吸血，最多10名|
|能量柱|beam|沿用原范围成长|沿用PP持续引导|
|连锁|chain|沿用跳跃次数成长|沿用延迟连锁、短暂停顿和敏捷加成|
|区域打击|meteor / trail|结算敏捷、耐力+80/150/250%|前摇延长、技能范围逐渐增至3倍，落点分布范围2倍|
|绽放|nova / aura|伤害+20/100/150%|范围+200%，每次有效命中25%概率眩晕1秒|

## 首轮试玩参数

参数集中在 `config/economy_config.json.classBonds`，便于后续调数值。

- 近战敌群收益上限：100%敏捷、20%实际伤害吸血。位移增加碰撞宽度，不延长冲刺距离。
- 陨石前摇从0.5秒变成1秒，预警期间半径从原值增至3倍；索敌/无目标落点范围2倍。地面轨迹先预警1秒，随后保留原有持续时间，并在此期间半径增至3倍；地面持续伤害落点在外围环带随机选择：外半径为max(160,最终溅射半径)×2，内半径为最终溅射半径×1.1；最多尝试16个可用地面位置，全部阻塞则本次不生成，不回落脚下。陨石本体的绘制尺寸与自身溅射范围同步从1倍成长至3倍。
- 绽放的冲击波通过投射尺寸和径向速度3倍扩大覆盖范围，光环直接使用3倍半径。
- 环绕每次技能冷却结束且成功支付PP时补满一圈，剩余未飞出的旧环绕物被本轮替换，已飞出部分独立存续，不占下一轮位置；移除逐个命中后等待1.2秒的补充规则。以施法者为中心按结算环绕半径×1.1索敌，发射速度420，飞行最多1.5秒；瞄准后保持直线方向，不追踪，0敌人穿透，命中沿途第一个敌人即可造成1.2倍环绕伤害并消失，目标可被其他敌人拦截。飞行无视墙体、岩石、树木及草丛，不因出屏幕、PP耗尽、普通环绕清理或临时副环到期而提前删除，战斗结束仍统一清理。未命中则正常飞行到期。alpha.24起首次敌人接触后强制删除，即使其他效果修改了穿透数或本次伤害为0也不再继续飞行。原始技能类型和伤害来源均保留orbit，不进入投射物羁绊和额外穿透成长。
- 炮台额外目标选择不同敌人，敌人不足时按实际数量发射，不对同一个目标重复补发。召唤数量提升作用于场上存量上限，保留单次施放数量。每名队员每招式同一施放通道最多128个召唤物，防止高层数无限堆积；持续时间和伤害仍按层数成长。
- 所有普通、精英和BOSS均可眩晕，BOSS持续时间减半。眩晕冻结移动、接触攻击、技能推进，已有场景投射物/范围危险和持续伤害继续结算。
- 穿透成长在有效命中结算后发生，不反向提高本次伤害。草丛不消耗穿透，因此不成长；实体可破坏物消耗穿透并触发成长。回旋保留返程行为，扇形保留原投射方式，不添加随机弹射、爆炸或额外暴击。alpha.22起，尺寸最多为初始6倍、碰撞半径最多128，参数为maxSizeMultiplier/maxRadius；达到尺寸上限后，伤害继续按每次穿透×1.2增长，保留浮点溢出余量。投射物生成时也应用半径上限，避免其他范围乘区放大初始尺寸后直接触发大范围区块生成。
- 二级羁绊使用带高光的独立职业配色，伤害元素不变。alpha.25起，普通技能、职业/属性/特性纯增伤及改造技能（含环绕发射和持续光柱）全部计入原宝可梦；只有独立新增的属性攻击（例如火爆炸、额外闪电链）单列羁绊来源。既有斩杀机制仍保留其来源；总伤害和DPS不重复计算。

职业标签同步用于编队、商店/战利品介绍、特性叠层与终端燃料、突破材料、野外匹配和后台DPS队伍快照。快照保留原物理 `kind` 并新增统一 `class`，旧历史记录不回写。

# 胜利选择与双倍金币（v0.14.0）

正常局中，角色存活时间首次超过 20 分钟时，立即记录本难度胜利、奖牌与下一星解锁。随后暂停战斗，弹出“本局游戏已经胜利”，提供两个选择：

- **结束战斗，领取双倍金币**：结束本局，将完整结算金币翻倍。
- **继续生存，挑战最强 Boss**：恢复战斗，保留本次胜利与已解锁难度，继续挑战 30 分钟的阿尔宙斯。之后死亡仍显示胜利。

每局只弹一次。遇到尚未结束的 Z 吟唱、道具／融合／升级选择时延后展示，不覆盖当前选择或打断技能；继续之后不会重复打扰。调试局、未解锁难度和未通过有效性校验的对局不触发领取弹窗。第八星显示已通关全部八档，不生成不存在的第九星。

## 领取机会

每个**账号、每档难度**各有一次双倍机会，共八次，同星级的不同宝可梦共享。只有成功用弹窗结束并领取后才消耗。

选择继续、继续后死亡、从暂停菜单普通退出、仅解锁或获得通关奖牌，都不消耗机会。此前已通关但尚未领取的难度，下次正常获胜仍能领取。已经领取的星级仍弹出胜利选择，但按钮与说明明确改为普通金币结算，不重复承诺双倍。

翻倍的是正常结算的全部金币：时间、击杀、Boss、拾取金币／宝藏之和，先经过原有幸运和难度倍率，再将取整后的正常金币总额乘 2。抽奖券、特性宝石、捕获和其他奖励不翻倍。

## 存档与失败处理

存档增加 `difficulty.cashouts[星级] = { coins, at }`，记录本次完整双倍金币及领取时间。旧存档默认全部未领取，合并按星级保留领取凭证；钱包和累计金币统计按凭证补齐已支付金额，避免较新的旧存档覆盖金币或恢复领取机会。只接受有效星级、时间及安全整数金额。

本地账号把完整双倍金币和凭证一起写入；云账号使用 Firestore 事务，并在同浏览器支持时通过 Web Locks 串行化，同一星级并发领取只支付一份。普通结算不会再次添加已经通过凭证支付的金币。重复点击在界面、对局状态与领取凭证三个位置防重。

房主领取保存失败时，弹窗保留，可重试或继续；本地保存失败会回滚本次领取，云事务失败不写凭证／金币。云领取需要连接服务器；普通结算仍沿用原来的本地缓存与后续同步机制。游客可以试玩，但领取状态和其他游客进度一样不跨刷新保存。

## 联机

房主达到胜利节点后暂停全队，房主选择结束或继续；队员显示等待说明。胜利暂停状态放入每份网络快照，避免遗漏单个事件后卡住；暂停期间不接收晚到的战斗指令。

房主结束时广播胜利结算，队员按自己的通关资格、有效性及对应星级的剩余领取机会领取。已领取者只结算正常金币；提前倒地且未达到生存目标者不取得双倍机会。某位队员领取保存失败时，该队员按普通金币结算并保留领取机会，不阻挡整队结束。房主选择继续时全员恢复，均不消耗机会。

## 验证范围

自动化覆盖 20 分钟边界、暂停与一次展示、继续后死亡、二倍最终结算、跨宝可梦共享、重复领取、保存失败与重试、旧档迁移／合并、注册本地账号重新登录、Firestore 模拟并发、同一凭证不重复加钱、八星文案和联机暂停／恢复／结束消息。

本地网页使用隔离端口与游客受控计时模拟验证正常获胜弹窗、继续后死亡再挑战仍能领取、240→480 金币、领取后同星只提供普通结算及弹窗收起。未修改个人存档、未连接用户云账号或排行榜；未进行真实双设备联机和线上 Firestore 试领。

# 竞技场玩法设计

版本：2026-11-19。**本版仅完成玩法设计与正常冒险镜像采集；尚未开放竞技场入口、AI 对战、竞技场榜单或发奖。** 用户确认的规则保留；未指定的数值与边界在下文标为建议，供正式实装时评审。

## 1. 独立赛季

- 竞技场是独立单人玩法，和正常冒险分别进入、结算、记榜。地表基准固定为标准六星，包括六星已有的刷怪、成长和精英规则；不随正常模式所选难度变化。
- 每周一个周期，北京时间每周一 04:00 换期。周期按服务器时间计算，区间为 `[本周一04:00, 下周一04:00)`，周一04:00之前仍属于上一期；不依赖玩家设备时区。周期编号使用起始日日期，星期、年份跨界均按实际时间边界处理。
- 每期规则、因子版本和随机种子一经开始即固定。普通阶段和镜像对战均应用本期因子；换期不在正在进行的对战中途更改数值。
- 建议：换期时封存旧期榜单并生成幂等奖励凭据。未结束的旧期对局可以完成并领取正常参与物资，但截止之后不能改写已结算榜单，也不占用新期排名。进场时明确显示本期剩余时间；新期开新局使用新规则。无跨期囤积分。
- 建议：账号达到六星解锁条件后开放正式记榜；游客可在后续加入练习入口，练习不入榜、无离线镜像积分。

## 2. 本期五个挑战因子（用户指定）

| 因子 | 规则 | 实装边界建议 |
|---|---|---|
| 冷冬 | 始终为暴风雪天气 | 以游戏现有 `snow` 为战斗基础，长期存在，覆盖地表和镜像场地；天气特性不能替换它。气闸仍可使天气效果失效，天气本身仍存在，不触发“无天气”增益。不是额外叠加一套伤害。 |
| 能量波动 | 能量柱伤害提高35% | `beam` 最终伤害乘1.35。 |
| 力量特训 | 近战／位移伤害提高35% | `melee`／`dash` 最终伤害乘1.35。 |
| 粒子散失 | 投射物伤害降低50% | `projectile` 最终伤害乘0.5；建议回旋 `boomerang` 沿用投射物归类。环绕、炮台、冲击波、扇形等按自身原始技能类型判定，不因视觉上有弹体被额外重复削弱。 |
| 经验匮乏 | 属性提升技能冷却时间延长200%；作为副技能时不会计入冷却 | `buff` 冷却时间为原来的3倍，位于副槽时冷却计时停止，切回主槽后继续；联合槽中的所有属性提升技能以该槽的主／副身份判定。不额外扣经验，PP仍沿用正常恢复规则，已有增益照常计时。 |

因子作用于我方和镜像，同一技能的每段伤害仅应用一次；对应 Z 招式按原技能类型继承，Mega、专精及场地效果不重复触发该乘区。属性提升技能原本不具备 Z 形态。首期采用以上全部五项，不额外随机增减；后续每期再配置新的组合。

正常模式完全不受这些因子影响。正常镜像采集保存实际原始战斗配置和版本；将来进入竞技场时重建角色，再施加本期规则，不能把已经受因子调整的结果再次乘算。

## 3. 挑战者勋章与挑战者之门

- 每局初始3枚挑战者勋章，不是收藏品，不跨局积累。
- 地表生存时间4／8／12／16分钟，各固定生成一次挑战者之门，落在玩家附近可到达的随机空地，存在20秒；小地图和屏幕方向提示同时标出。不替换其他特殊事件。
- 门未进入就消失，不扣勋章。建议：遇到裂缝场地等暂不能展示的状态时，记住该时间点，返回地表后展示该门，20秒从其实际出现且玩家可行动时起算；暂停、选择卡牌不消耗门的有效时间。不能重复触发同一时间点。
- 玩家进入后恢复满生命，地表敌人／弹幕／拾取物暂存，生存时钟与地表事件停止。进入独立封闭场地，与相近生存时间玩家的镜像一对一对战。
- 双方对战生命上限、当前生命提升至各自正常值的10倍，只应用一次。建议3秒开场倒计时，双方不能行动，不生成伤害；结束后开放攻击。
- 对战不提供受击无敌，也取消位移、Z吟唱、Z结束保护等无敌／高额免伤窗口中的“免疫”部分；保留正常防御、减伤与技能倍率。取消的只是无敌机制，单个攻击自身的命中间隔、弹丸去重仍保留，不能把同一碰撞变为每帧无限命中。镜像本体不产生普通野怪式接触伤害。
- 技能CD、PP、增益持续、道具CD、Mega持续及充能等战斗计时在对战中正常运行；它们和地表生存时钟分别计时。初始镜像的生命、PP与CD建议归一到正常开战状态，其他配置、技能与专精保持；我方进入时只按已指定规则回血，不无条件补充Z充能或稀有消耗品。
- 对战获胜：获得额外分，记录胜场，返回原地表位置附近的空地。对战失败：失去1枚勋章，仍有勋章则返回地表继续；失去最后1枚才结束整局。
- 建议：地表死亡也消耗1枚勋章，尚有勋章时清开附近敌人、恢复生命后继续，避免竞技场仍因一次普通死亡绕过三枚勋章规则。返回生命按竞技场前未扩大上限恢复，不能把10倍临时生命带回地表；道具消耗与永久成长保留。

## 4. 维度不稳定

开战40秒后，每0.2秒双方各结算一次递增伤害。不受任何防御、减伤、护盾、无敌或护命道具阻止，不给予反伤／吸血／受击触发收益，避免靠该机制循环续命。

建议公式：令 `H₀` 为本场开战时10倍后的生命上限，第 `n` 次（n从1开始）伤害为：

`D(n) = H₀ × (0.001 + 0.00025 × n)`

侵蚀10秒约累计消耗36.9%开场生命，17秒约99.9%，之后继续增长；治疗可以暂时延长战斗，但不能无限拖延。基准固定为入场上限，不因重伤降低而越打越轻。暴风雪等其他环境效果照常存在，但不与维度侵蚀重复记录为镜像攻击。

双方在同一物理步死亡建议视为平局：无胜利额外分，我方扣1枚勋章，镜像持有者无胜利积分；不按渲染先后偏袒一方。死亡后本场只允许一个结算回执。

## 5. 终极挑战

- 地表生存时间达到20分钟，停止普通地表流程，进入终极挑战，不再出现正常20分钟胜利双倍金币选择，也不进入30分钟阿尔宙斯流程。
- 对手优先来自已经参加终极挑战的玩家镜像；目前尚无该来源，临时使用正常模式20分钟镜像作为“先行训练镜像”。不能把它标作已验证的真实终极挑战战绩。未来真实终极镜像池逐步替换引导池。
- 每次击败镜像后，打开通向下一名对手的传送门；玩家进入后继续。建议门间阶段不受维度侵蚀，可查看背包，不能通过等待刷生存分、充能或增益。
- 玩家失败时失去1枚勋章，尚有勋章则继续挑战新对手；全部失去后结束。建议每场入口恢复至当前允许的生命上限，保留累积重伤与道具消耗；失败不会刷新重伤。
- **重伤（用户指定）**：我方受到镜像玩家的实际生命伤害，其10%转为等量生命上限削减。按经过防御、减伤和护盾后真正扣除的HP计算，过量致死伤害不多算；环境伤害、维度侵蚀、自伤不产生重伤。
- 建议实现 `H当前上限 = max(1, H正常战斗上限 − 重伤累计)`。例如一次真正掉血1000，累积重伤100，上限减100，当前HP裁到新上限；治疗、切形态和Mega往返不能清除重伤。倍率改变时保留重伤绝对量，防止反复变身洗掉惩罚。显示独立重伤条与减少的上限。
- 终极阶段的生存时钟固定20分钟；对战时间和连胜数另外展示，不通过竞技场停留增加普通生存分。

## 6. 镜像与AI

先按4／8／12／16／20分钟桶匹配，再优先本版本、正常六星和相近等级／构筑强度。建议优先参考攻击、生命、技能等级和专精，而不只看角色等级；小池时逐步放宽，保持真实构筑，不暗中凭空加属性。

排除本人、封禁／注销账号、已判定调试的对局、格式不兼容或过旧快照；尽量避开最近三场的同一镜像持有者。一次对战创建后固定镜像与随机种子，不能断网换对手。对手名称和头像到时通过账号展示资料读取，不把口令、Cookie或恢复码放进快照。

建议AI模板：

| 技能倾向 | 行为 |
|---|---|
| 近战／位移主导 | 靠近、侧绕、在关键技能就绪时突进，技能真空期短暂脱离 |
| 投射物／能量柱主导 | 保持射程，预测方向，避免贴身停留 |
| 环绕／光环主导 | 保持有效命中距离，围绕目标横向移动 |
| 地雷／炮台／轨迹主导 | 争夺区域，诱导对手进入持续伤害范围 |
| 联合／均衡构筑 | 根据PP、冷却和对方距离切换主要槽，保留次槽并行规则 |

采用最近60秒的实际技能释放次数、主槽切换、移动／近远距离时间、Z使用等选择模板与权重。AI读取和玩家相同的场面信息，遵守PP、CD、施法锁定、地形与本期因子；建议保留0.15—0.30秒反应延迟，不以读取尚未发生的输入做到必闪。

重建从八项IV、属性基底、成长、装备、技能、专精和状态出发；记录的最终属性用于核对，不再次叠加进化／等级／Mega收益。旧数据只有在兼容迁移明确时才进入正式匹配，否则作为训练数据保留，不勉强执行旧脚本。

## 7. 得分与两个榜单

用户指定：顶分榜比较单局最高分；挑战者榜比较累计挑战者积分；本人额外得分兑换积分，自己的镜像击败挑战者也获得积分，可离线入账。

建议首版数值：

| 来源 | 建议额外分 |
|---|---:|
| 4／8／12／16分钟门胜利 | 2000／4000／6000／8000 |
| 终极挑战第n胜 | `10000 × [1 + 0.12 × min(n−1, 10)]` |
| 平局／失败／不进门 | 0 |

建议总分 `= 正常六星地表得分 + 挑战额外分`。额外分已按门次和终极层数计价，不再乘一次六星5.2倍，不受金币加成影响。

本人挑战者积分 `= floor(本局挑战额外分 / 100)`。结束时结算，放弃只结算已完成胜场；每场对战的胜利回执先持久化，网络失败可补交同一凭据。镜像胜利建议给予其主人20分，仅在对方确实因此损失一枚勋章后发放；本人／同一账号不能互刷，同一挑战者对同一镜像主人每日最多计分一次，镜像被动积分每日上限100，离线自动入账。上述倍率、奖励与防刷上限是建议，不是本版已实现逻辑。

- 顶分榜：本期各账号单局最高分；同分先比较终极胜场，再比较首次达成时间，最后按账号ID稳定排序。
- 挑战者榜：建议本期累计的主动+被动积分；本期结束归档并清空本期榜，终身累计单独展示，避免后入场玩家永久追不上。两种榜单均保留个人名次。
- 周期内积分不扣作消费；若以后增加兑换商店，另设可消费余额，不让消费影响榜位。
- 周榜只使用已结算的服务器对战凭据；服务器负责对手分配、重复结算与奖励限额，不中转战斗。客户端战斗结果仍需要后续校验策略，不能把当前快照结构检查当作完整防作弊。

## 8. 每周奖励建议

两个榜分别按以下档次结算。物资可叠加；名片外观合并展示该期最高名次，分别标注榜单来源。外观为收藏奖励，不增加战斗属性。

| 名次 | 个性化奖励建议 | 物资建议（金币／抽奖券／特性宝石） |
|---|---|---|
| 第1名 | 本期编号冠军名片、动态桂冠、冠军称号 | 20000／100／20 |
| 第2—3名 | 本期编号银／铜冠边框、领奖台称号 | 12000／60／12 |
| 第4—10名 | 前十专属挑战纹章与名片底纹 | 8000／40／8 |
| 第11—50名 | 本期竞技场贴纸 | 4000／20／4 |
| 完成至少一场挑战 | 本期参与标记 | 1500／5／1 |

每榜每期每账号只取最高档，生成唯一奖励凭据；建议保留30天登录领取，离线玩家照样保留资格，不因服务重启重复发放。冠军外观带期号防混淆，终身收藏与本期榜单分开。具体物资量在首期上线前根据普通模式产量复核。

## 9. 本版镜像记录器（已实现）

- 仅采集登录账号的正常单人、有效正式构建对局；4／8／12／16／20分钟各一次，采用游戏生存时间，支持已解锁倍速。不追补跳过的旧时刻，不采集死亡状态、游客、组队或调试局。没有视频、输入逐帧回放或持续战斗上传。
- 设置→操作增加“保留挑战镜像”，默认开启；关闭影响后续采集，不声称能撤销已经上传的样本。采集失败不会影响对局存档、结算或普通排行。
- 战斗格式schema1：八项IV、属性基底／永久成长／局内成长／最终战斗值、当前形态与进化路线、技能等级／超武／专精／PP／CD／联合槽／主次槽、增益、特性状态、主动和特殊道具、Mega／Z状态、最近60秒行为倾向。未来对战重建与AI尚未实现，不把此格式等同于完整战斗录像。
- 本机待上传队列按账号隔离，最多30份、7天；正常心跳和结束回执携带本局最多5份并确认去重。旧后端不附带快照；独立后台批次负责历史补传，不拦住钱包上传、不显示网络失败弹窗。
- 服务端按账号、对局、时间桶、正常模式、已汇报时间、构筑结构和体积验证；单条上限32KiB，只保留明确白名单字段，数据库gzip压缩。唯一键为对局+时间桶，重复回执不重复落库。后续汇报为调试时删除该局已有镜像；注销时删除该账号样本。
- 每账号每个时间桶最多3份（共15份），样本保留35天；后台在接收时最多每小时做一次年龄／全局50000份上限清理，不扫描全部战斗帧。服务器可用 `MIRROR_RECORDER=0` 关闭采集，普通玩法照常结算。
- 当前记录器不发放挑战者积分、不生成AI／挑战门／竞技场排行，不改写普通模式属性。镜像数据来自客户端，记录不是验证过的真实竞技胜负；正式竞技场还需实现独立对战凭据和排名验证。

## 10. 分阶段实施

1. 当前：采集正常镜像、冻结规则与首期五因子；部署后先观察时间桶覆盖、快照大小与失败率。
2. 训练对战：封闭场地、镜像重建、AI、无敌移除、维度侵蚀，先不发排行榜奖励。
3. 完整单局：4次门、勋章、20分钟终极连战、重伤与额外计分。
4. 周期服务：两榜、对战凭据、离线镜像积分、周奖励、历史与外观。

上线采集需要更新网页和Node并重启服务，SQLite自动创建新表，不需要重建或清空玩家存档。Git推送不等于生产部署；生产目标、连接方式与备份路径确认后再执行。记录器运维见 [MIRROR_RECORDING.md](MIRROR_RECORDING.md)。

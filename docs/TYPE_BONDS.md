# 属性羁绊 · v0.43.0-alpha.7

接续中断的18属性实现；设计来源为 `羁绊设计文档.xlsx` 的 Sheet1 A1:E19。蛋组与其他未设计职业保持留白。

## 公共规则

- 沿用每个标签按不同名字去重、队长计数、倒下上阵者计数、候补不计数；2/5档累计解锁。部分效果作用于队长或全队，按下表说明。
- 属性羁绊默认0层即有基础效果；0/100/300层对应三个数值节点，区间线性插值，300之后延续后段斜率。层数不改变生效人数；当前没有自然获取层数的途径，不写入账号。原五职业仍默认1层，0层关闭。
- 伤害基准沿用中断草稿：存活上阵同属性成员的最终物攻与特攻之和×30%，并参与属性与天气及原伤害管线。当前生命百分比流失单独处理，Boss减效。
- 属性触发以攻击者自身属性决定；多段返PP按原始施放编号去重。新增伤害带来源标识，避免点燃/感电/龙星群等无限自触发。
- 虫系牺牲仅移除本阶段队员的战斗能力，队长保留；下阶段恢复。每阶段重置持续场、护盾、计数及临时继承，不清除本局羁绊层数。
- 源码F2可选择属性、设置层数及生成同属性测试小队；调试局排除排行榜。正式构建排除该开发模块。

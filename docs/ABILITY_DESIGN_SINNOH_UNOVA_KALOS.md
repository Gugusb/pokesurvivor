# 神奥、合众、卡洛斯特性设计

状态：本表所列特性在 v0.5.0 实现。记录日期：2026-10-15。合众后续特性和卡洛斯仍待设计。

沿用每只宝可梦每个特性一枚勋章、同时只能装备一枚的规则。已有同名特性沿用此前确定的实现，除非本表明确重做。

| 特性 | 用户设计 | 已确认细节与实现 |
|---|---|---|
| 沙隐（用户已确认名称） | 免疫沙暴伤害；沙暴天气时获得已有加速 buff。 | 复用轻金属加速：每层移速 +20%，持续 5 秒，最多 3 层，共用刷新时间。沙暴生效后立即获得一层，此后每秒增加/刷新一层；结束后保留至 5 秒计时耗尽。 |
| 粗糙皮肤 | 受到接触伤害时立即发动一次等级 1 的近战技能，即使未学会；内置冷却 1 秒。 | 用户确认固定等级 1 撞击；朝接触攻击者方向发动，不增加技能槽、不修改所学技能及其冷却。 |
| 火焰之躯（重做） | 受到接触伤害时，击退周围攻击者并将其灼伤 5 秒；每秒伤害正比于自身攻击力；内置冷却 1 秒。 | 用户确认必定触发、半径 120 世界单位，总灼伤沿用此前一发火球伤害。施加时记录伤害，每秒一跳，共 5 跳；重复刷新而不叠加。击退沿用游戏规则，对 Boss 无效。 |
| 飘浮（加强） | 自身不会触发地面陷阱；保留既有穿越障碍、禁止施法和移动惩罚。 | 无。 |
| 心灵感应 | 受到与自身任一属性相同的伤害时，减伤 50%，并恢复 5% 最大生命；内置冷却 1 秒。 | 用户确认同属性始终减伤；仅回血受 1 秒冷却限制。实际扣血后回血，不救回已被该次攻击击倒的角色。 |
| 引火 | 受到火属性伤害时，获得助燃 buff：攻击力 +50%，持续 5 秒，不可叠加。 | 无；重复触发刷新持续时间。 |
| 慢启动 | 获得经验速度 -30%；升级时有 50% 概率额外获得一次技能选择。 | 无；额外选择不额外提升等级，也不再次触发概率判定。 |
| 湿润之躯 | 下雨时免疫所有 debuff。 | 当前主要涵盖陷阱、地形和天气减速；伤害本身不视为 debuff。 |
| 梦魇 | 被减速的敌人每秒失去 5% 当前生命。 | 无；按当前生命而非最大生命计算。 |
| 多属性 | 无视所有系别效果，受到伤害总是降低 20%，造成伤害总是提升 20%。 | 属性克制表视为 ×1；天气仍按天气规则结算。覆盖近战、弹道、场地、持续伤害、环境伤害和生命宝珠；联机由伤害权威端施加一次伤害加成。 |
| 胜利之星 | 自身投射物技能的弹道速度加快 30%。 | 覆盖普通弹道、散射、锥形、炮台和回旋镖的去返程速度；不改变环绕技能的角速度。 |

## 本轮涉及的普通形态

- 烈咬陆鲨：沙隐、粗糙皮肤。
- 由克希、艾姆利多、亚克诺姆、克雷色利亚：飘浮。
- 帝牙卢卡、帕路奇亚、骑拉帝纳（别种形态）：压迫感、心灵感应。
- 席多蓝恩：引火、火焰之躯。
- 雷吉奇卡斯：慢启动。
- 霏欧纳、玛纳霏：湿润之躯。
- 达克莱伊：梦魇。
- 谢米（陆上形态）：自然回复。
- 阿尔宙斯：多属性。
- 比克提尼：胜利之星。

神奥 15 只、20 枚勋章全部开放；合众先开放比克提尼 1 枚勋章。合众其余五星仍按原概率抽出宝可梦，保底文案明确为五星奖励。总计 42 只宝可梦、63 枚勋章。

合众其余新特性、卡洛斯新特性及形态特性等待后续设计；本表不自动把尚未设计的特性加入卡池。

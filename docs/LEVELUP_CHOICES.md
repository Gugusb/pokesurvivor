# 升级选项规则

v0.8.1，2026-10-16。

- 每次生成三张不同的奖励卡，包括正常升级、刷新和慢启动额外选择。
- 普通抽取先选类别：输出技能、被动永久属性卡、属性增益技能的基础权重为 **5∶3∶2**。属性增益技能指剑舞、高速移动、变硬、水流环、龙之舞这类 `buff` 技能；永久属性卡包括生命、攻击、速度、防御、经验等。新学和升级技能都归属对应类别。无候选的类别不参与抽取，剩余类别重新分配概率；不是每组三张固定配额。
- 类别内部，新技能权重 1；已学且尚未满级的技能权重为 `2 + 0.75 × (当前等级 - 1)`，即 1–4 级分别为 **2、2.75、3.5、4.25**。使用完整的合法技能池，保留属性学习范围、禁止技能、四栏限制及最多两个增益技能的原有限制。
- 已学技能满级且满足原进化条件时，以超武进化卡替代升级卡，权重降至 **0.75**，取消原来的必出。类别权重也会按超武候选相对于 4.25 的降权比例折减，防止“只剩一张超武输出卡”时类别归一化抵消降权。尚缺的进化条件属性卡保留提示、内部权重为 2，普通属性卡权重 1。
- 若一轮没有出现已学技能的升级卡，且仍有未满级技能，下一轮至少出现一张升级卡。刷新也计一轮，不要求玩家实际选它；增益技能升级、非当前选中的技能、融合栏中的技能都有效。每位玩家独立计数，新局重置。
- 所有已有技能都满级时不强制出卡；可进化的超武仍只按低权重随机出现。之后学习新技能时重新开始保底计数，不继承满级前未触发的保底。保底优先于类别比例，因此实际总体比例会随技能栏、满级情况和保底发生变化。
- 技能的实际升级、进化效果及刷新次数规则保持原逻辑。本地与联机队员都通过同一选卡生成入口，保底不写入永久存档。

验证：`node --test tools/test_levelup.cjs`；覆盖 30,000 次类别抽样、2,000 轮保底序列、真实刷新 UI、满级、满栏、融合、增益技能、超武唯一输出候选及实际选卡应用。

# 远征队员特性组成调整方案

- 文档版本：1.0 草案
- 日期：2026-11-28
- 数据基线：v0.43.0-alpha.85，提交 `5723ec65cdd1778134794e9ec252e67d087491a1`
- 状态：设计与统计方案，尚未修改游戏数据、运行逻辑或玩家存档。

## 一 调整目标与硬约束

减少低品质队员中“依靠已有羁绊层数提高自身属性”的终端特性，增加经济型、主动叠层手和Buff手，使队伍形成“生产资源与层数、支援伙伴、由少数终端兑现收益”的构筑关系。

用户目标是上述三类合计与叠层终端接近8∶2。5品质的现有叠层终端，尤其传说宝可梦，保持不变。为避免扩大修改范围，本方案进一步将全部5品质家族的现有特性冻结，包括非终端；不改品质、星级、进化链、技能或职业标签。

本方案将“低本／5本”暂按宝可梦品质1—4／品质5理解，不按商店等级解释。商店等级只改变各品质出现概率，不会改变同一家族的特性。

**当前存在统计约束冲突：5品质已有135个终端家族，占全部509家族的26.52%。保留它们时，无论怎样替换低品质终端，都不可能把全家族的终端占比降到20%。** 文档分别列出家族与物种口径的可行方案，不能通过更换分母宣称两者同时达标。正式实施前需要选定验收口径，本轮只形成文档。

## 二 四类特性的定义

| 类别 | 判定依据 | 当前归入的效果 |
| --- | --- | --- |
| 经济型 | 直接产出局内资源，不靠羁绊层数转换自身属性 | 金币、训练家经验、宝可梦经验、免费刷新 |
| 主动叠层手 | 由持有者的实际战斗行为主动生产已激活羁绊层数 | 自身施法、自己击杀触发的自身／邻位／最高层属性加层 |
| Buff手 | 直接治疗、增加队友属性或提供支援，不以已有层数为收益燃料 | 邻位施法治疗、队长治疗、邻位双攻／敏捷耐力／暴击增益；新方案可扩展临时增益、白盾、PP补给 |
| 叠层终端 | 将已有羁绊层数转成自身战斗属性或复活能力 | 属性层数转双攻、属性层数转双防、职业层数转敏捷耐力、传说层数转属性、幻兽层数转复活 |

“主动”指依靠自身战斗行为自动触发，不新增手动按钮。队员换成叠层手或Buff手后仍正常施放自身技能，不强制变成辅助职业。

当前还有战后、休息、买经验、升星等条件加层。现状统计将它们归为“叠层供给”，但单独区分主动与日程触发；不能把所有条件加层都称作主动叠层手。目标方案新增的叠层供给全部采用自身施法／自身击杀，让主动生产者真正增加。

旧数据的 `independent`／`conditional` 只是触发形式，不等于终端／支援。独立的施法治疗属于Buff；条件永久加邻位属性也属于Buff。已有层数转自身复活仍计入终端，不通过重新命名来降低终端占比。混合效果只占一个主要类别，不重复计数。

### 推荐与待定口径

从商店实际构筑出发，建议优先以家族为主要审计单位，将“不动5品质”作为高于比例的硬约束。方案A给出可达到的上限；若更重视1—4品质保留少量终端，并接受以完整物种目录验收8∶2，则采用方案B。

本轮不擅自将方案B的物种比例写成用户已经确认的最终口径，也不擅自删改5品质终端。若坚持509家族严格20%终端，只能保留约102家族，至少要改动33个受保护5品质终端；或者在全部低品质终端已移除后新增166个供给家族，使135／675=20%。两种做法都超出本轮范围，不采用。

## 五 低品质替换优先级与分配原则

1. **先处理品质1。** 让前期拿到的队员能主动提供层数、资源和保护，不必等高层羁绊才有特性收益。
2. **再处理品质2。** 补齐常用职业和属性路线的生产者，减少只有低品质终端互相等待层数的开局。
3. **品质3强调稳定发动与多种构筑方向。** 保留名单以外的终端转为中期生产者，不能仅把所有攻击终端统一改成金币。
4. **品质4强调队伍支援与高效生产。** 可以拥有更强的邻位增益和更合适的触发条件，但不复制5品质传说的全属性转换。
5. **品质5全部冻结。** 不顺带削弱终端系数、复活次数、层数来源范围或修改职业。

新分配只替换终端。已有经济、叠层供给和Buff家族原则上保留，不通过洗掉已有供给来反复重新抽签。新分配需记录“原效果、目标类别、具体触发、收益、理由”，逐家族生成可审查清单，而不是运行时随机决定。

在同一品质内部，按职业、属性与世代分层分配配额：先保证每个样本足够的职业至少有经济、叠层、Buff三种路线，再尽量让不同属性都能找到主动叠层手。双属性只用于覆盖检查，不让一个家族重复占用总配额；只有少量家族的分组不强求三类等分。

### 主动叠层供给的独立目标

方案A新增118个叠层家族全部采用自身行为：建议80个施法触发、38个击杀触发。叠加现有11个主动生产者，共129／160=80.63%的叠层供给为主动型。

方案B新增112个叠层家族：建议74个施法、38个击杀。共123／154=79.87%的叠层供给为主动型。保留原31个日程条件供给，不为了比例强行更改其玩法。

施法型应多于击杀型，使辅助、低输出和正在培养的成员也能生产层数。击杀型优先安排给能实际拿到击杀的职业，不能主要塞给不造成伤害的辅助招式成员。

## 六 新增经济型模板

经济型包含经验和刷新，不等于全部发金币。建议新增45个经济家族中，金币10、训练家经验10、宝可梦经验15、刷新10；与旧55个经济家族共同存在。

以下为新模板试玩值，不是对旧经济家族数值的静默覆盖。总经济需要连同旧特性实测，但本轮首先做分配设计，不恢复战斗地面金币掉落。

| 模板 | 行为与收益 | 频率边界 |
| --- | --- | --- |
| 跟队工资 | 上阵存活完成2场成功战斗，战后获得1G | 每个持有者累计；同一场由本轮新增金币模板实际发放全队最多1G，未轮到的已完成资格顺延，队列按资格时间处理，不无限追加待领资格 |
| 战斗记录 | 自身累计完成80次普通技能施法，战后获得1训练家经验 | 自身跨战累计，每名每场最多1次；新增同类每场全队最多2点，不由经验收益反向刷计数 |
| 清扫笔记 | 自身累计击败20名敌人，获得20／30／40宝可梦经验（1／2／3星） | 每名每场最多2次，战后发放，不计友方和额外复制击杀 |
| 休整作业 | 完成一次休息事件且持有者上阵存活，为经验罐填充20／30／40点 | 同一个事件只结算一次；不直接生成训练家等级，不重复乘经验获取倍率 |
| 采购助手 | 上阵存活完成3场成功战斗，获得一次免费刷新 | 次数只按触发发1次；本轮新增刷新模板全队每周期最多发2次，达到额度后不继续排队；不能在流浪商人处使用 |

金币、训练家经验和刷新优先采用小额整数、进度与次数限制，不直接套用“收益底数×星级×品质”连续放大。宝可梦经验采用明确的星级表。该方案使低品质经济成员可以发挥作用，同时避免替换45个家族后重新出现一场特性收入抵数场工资的问题。

新金币模板的待发队列需要在UI中显示；若不希望引入队列，可在正式定稿时改为全队共享进度，不使用“被上限截掉但界面仍承诺发钱”的规则。

## 七 新增主动叠层模板

沿用已激活标签与现有接口：只给持有者自己或明确邻位实际拥有、且已经激活的属性／职业羁绊加层。本轮不顺带将蛋组加入现有队员特性的有效层数范围，也不增加羁绊人数。

| 模板 | 触发 | 收益底数 | 对象与限制 |
| --- | --- | ---: | --- |
| 练招积累 | 自身普通技能施法20次 | 2层 | 自身一条已激活职业羁绊；有多条时按实际触发招式的统一职业选择 |
| 属性磨炼 | 自身普通技能施法25次 | 2层 | 自身已激活的首属性羁绊；首属性未激活则进度最多停在门槛前一次，不转加无关属性 |
| 邻位配合 | 自身普通技能施法30次 | 1层 | 前后各一位存活成员拥有的已激活属性／职业羁绊；同一条每次只加一次 |
| 击破积累 | 自身击败15名敌人 | 2层 | 自身一条已激活职业羁绊，按当前主技能职业选择 |
| 主力供能 | 自身击败30名敌人 | 3层 | 全队当前层数最高的一条已激活属性羁绊；没有激活属性时进度停在门槛前一次 |

新增层数按现有星级权重1／1.5／2与品质权重1／1.2／1.5／1.6计算一次并向下取整；UI显示最终值，不再次乘权重。例如底数2在1星1品质为2层，在3星4品质为6层。

每个普通技能完整施法记一次；持续光柱每跳、炮台自动射击、地雷爆炸、环绕命中、羁绊额外攻击不视为持有者新施法。融合中每个实际正常施放的招式各计一次，但一次招式多目标命中不重复计数。击杀归属仅持有者自己，仍跨战保留进度。

新增单体同一加层模板最多每游戏秒触发一次，超出时只保留至一次完整待触发进度，避免极端攻击速度批量结算。未激活羁绊不积存多次完整奖励，之后换阵也不能瞬间倾倒历史层数。

这些模板的目标是“零层也能启动、升星后生产更明显”，不是让低品质生产者自身再次按层数获得全属性。触发速度应与实际职业相适配，20／25／30次与15／30次击杀仅为试玩门槛。

## 八 新增Buff手模板

新增33个Buff家族建议优先分配临时属性支援20、治疗／护盾／PP支援13。新增模板不再一律永久加面板，减少跨战无限堆积，同时给编队前后位安排明确价值。

| 模板 | 触发与效果 | 上限及边界 |
| --- | --- | --- |
| 鼓舞邻位 | 自身每完成20次普通施法，前后存活成员双攻提高4%×星级权重×品质权重，持续8秒 | 最多15%；同模板同目标取较高值并刷新，不叠层，触发冷却12秒 |
| 节奏指挥 | 自身每完成20次普通施法，为前后存活成员下一次普通招式提供6%×星级权重×品质权重的基础敏捷增幅 | 最多18%，保存最多6秒、使用后移除；冷却12秒，按alpha.83敏捷乘区接入，不独立连乘 |
| 守备照看 | 自身每完成25次普通施法，前后存活成员双防提高6%×星级权重×品质权重，持续8秒 | 最多20%，同源不叠，冷却12秒；不直接改最终减伤 |
| 邻位急救 | 自身每完成6次普通施法，为前后生命比例较低的一名存活成员治疗自身最大生命2% | 每次不超过受疗者最大生命3%；与现有战斗治疗共享限速，不复活、不治疗自身，无目标不囤多份 |
| 开场护航 | 每场开战给前后各一位成员3%／4%／5%目标最大生命白盾（1／2／3星），持续8秒 | 不额外乘品质，与现有白盾共用上限；不触发反复开战领取 |
| 补给接力 | 自身每完成25次普通施法，为前后普通PP比例较低的一名成员当前主技能恢复1PP | 冷却10秒，只恢复缺口；不为自己补PP、不递归计施法或补给，不提前解除近战归队禁攻 |

已有治疗和永久邻位增益家族保留其当前特性；表内是被替换终端的新候选。辅助技能家族可优先承接Buff，但不能把“Buff手”全部限制为辅助职业，也不能为了分类强行更换所有人的固定招式。

## 十 分配与实施步骤

1. 固定实现时最新数据快照，并重新审计；本文件数值绑定alpha.85，不用旧69.94%的“独立特性比例”替代终端比例。
2. 确定方案A／B及验收分母，先锁定全部5品质家族，再锁定可选的少量中品质保留名单。
3. 为剩余终端按品质配额、职业与属性覆盖、原物种主题分配E／S／B类别；不修改非终端家族来凑数。
4. 生成逐家族迁移清单，列出根ID、品质、成员、原效果、目标效果、触发条件、1／2／3星最终值、保护原因。人工复核后再改源JSON，生成运行数据与目录，不手改生成文件。
5. 条件Buff、PP支持与新资源额度需补充对应运行接口；本轮设计不宣称所有新模板已能直接挂入现有代码。
6. 同链共享新特性。已存在远征局采用版本化规则：建议旧局继续使用旧版分配，新局采用新版；先补全可持续读取旧特性的版本表，不能只写一个版本号却继续读取最新映射。
7. 敏捷、治疗、PP、金币结算复用最新接口。所有计数与待兑现收益进入存档，不改队长特性、羁绊人数或卡包权限。

## 十一 验收与平衡观察

### 静态验收

- 509家族、966物种完整覆盖；没有重复、缺失和拆链；所有5品质特性及数值逐项保持不变。
- 输出家族比例、物种比例及各品质比例，不混用分母；方案B同时验证193个终端物种，而不是只验证141个家族。
- 新增主动叠层模板真实依赖自身行为；生成物、持续跳伤与额外攻击不会刷施法计数。
- E／S／B不是终端改名：层数转自身属性仍必须列入终端，不能加个微小金币效果就改计经济。
- 每个样本足够的职业与属性路线都有可用生产者；不能只让高输出角色能够拿到层数和资源。
- 本轮保留5品质的alpha.83传说属性范围，不回滚最新规则。

### 必要玩法验证

- 低品质队伍零层开局能开始生产，不必先得到高品质终端；邻位Buff和PP补给能实际触发。
- 对比早期、中期、关底三种代表构筑的全清率、队长失血、小队损伤、层数增速、经济收入和队员DPS，识别低品质终端减少后的战力缺口。
- 先调生产者门槛、单次层数、Buff覆盖率，不直接给全队叠一个补偿性全局伤害倍率，也不借机削弱5品质终端。
- 抽取体验按实际商店概率审计：终端出现概率为各品质出现概率×该品质终端家族占比之和，按本局合法卡池／库存重新归一。三世代局内池不等于全部509家族，全球目录8∶2不保证每局商店8∶2。
- 检查金币、训练家经验、免费刷新总收益，尤其旧经济特性与新增家族同时上阵时，不能只测新模板单体。
- 检查暂停、多倍速、战后重复打开、升星、换招、存档续玩，以及满血／满PP／未激活羁绊等边界。文档阶段只完成统计核对，不声称已经做过以上玩法验证。

## 十二 本轮结论

优先级明确：保护全部5品质，重点替换品质1—4的叠层终端，新增供给以自身施法／击杀的主动叠层手为主，经济收益小额且有边界，Buff通过邻位与短时状态形成编队价值。

严格家族8∶2与“不动5品质终端”当前不能同时成立。已给出最接近家族目标的方案A，以及物种口径接近8∶2、保留少量中品质终端的方案B；没有在代码中擅自选定其中一种。

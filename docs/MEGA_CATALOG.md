# Mega 素材加入与缺失清单

版本：v0.7.0，2026-10-15。

核对来源：[SpriteCollab 固定快照](https://github.com/PMDCollab/SpriteCollab/tree/e7868e9a7f6b931d1fb826756a490d4633879d03)。按库中登记的独立 Mega 形态统计；X/Y/Z 分别计数，异色不重复计数。排除替代配色/画法槽、袋兽宝宝、暗影和原始回归。保留原始颜色玛机雅娜与米立龙不同姿势的独立槽。

共 96 个形态：36 个达到基本动作标准且全部已加入；另保留 4 个旧版部分完成预览，共 40 个可用。56 个未加入。

“基本达标”指源登记 `sprite_complete >= 1`；最高完整级为 `2`（超级大嘴娃）。基本达标不保证拥有游戏的每一种独立动作，射击/倒下等仍可能复用同形态动作；逐项映射见 [素材署名](MEGA_ASSET_CREDITS.md)。

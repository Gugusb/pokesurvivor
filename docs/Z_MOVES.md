# Z 招式试玩版（v0.12.0）

## 操作与装备

- 首版仅在设置开启开发者模式后，由 F2 面板获得 Z 石；图鉴详情可装备或卸下。Z 石与 Mega 石互斥，占同一特殊槽位。佩戴后普通道具拾取转为经验。
- 开局就绪。点击 Z 石或按 F 进入蓄力选招，同属性且属于下表七类的技能亮起；点击技能或按 1–4 立即释放。再次按 F 可取消尚未释放的蓄力。
- 选择期间所有玩家与世界按 10% 速度运行；释放后恢复正常速度。联机通信保持原频率。
- 施放者在选招及整段施放期间无敌。普通攻击停止，不可切换技能，升级与普通道具选择延后。同一槽位内所有符合条件的技能一起释放，以最后一个完成为准解除锁定，然后 Z 石冷却 180 游戏秒。2 倍速会相应加速游戏秒。
- 保留正常的属性克制、暴击、天气和特性伤害结算。原技能等级决定基础参数，Z 倍率独立应用，不改写普通技能数据。

## 已实现的七类

| 类型 | Z 效果 |
| --- | --- |
| 投射物 | 优先朝 Boss，否则朝敌人最多的半圆中心；以 30° 间隔扇形发射五枚，尺寸 ×5、穿透 +999、基础伤害 ×20、弹速 ×3。锁定至少 1.2 秒，技能原投射物寿命更长时取其寿命。 |
| 近战 | 1.2 秒内连续转三圈，每圈每敌人命中一次，半径 ×3、伤害 ×20；随后蓄力 1 秒，再以半径 ×4.5、伤害 ×30 命中周围一圈。共 2.2 秒。 |
| 能量柱 | 优先 Boss，否则朝覆盖敌人最多的直线；固定起点、方向，持续 3 秒，立即及随后每 0.5 秒造成一次，共 6 次；伤害 ×10、宽度 ×4、长度 ×99。 |
| 环绕 | 持续 5 秒；外层半径 ×1.5，顺时针转速 ×3、伤害 ×10；内层半径 ×0.75，逆时针转速 ×2、伤害 ×20，并减速 80%。两层各保留原技能环绕物数量及命中间隔（最低 0.12 秒）。 |
| 连锁 | 持续 5 秒，每 0.5 秒一轮，共 10 轮；伤害 ×10，连锁数量 +20、减速 80%。可回到之前命中过的目标，但不能把当前目标作为下一目标。 |
| 冲刺 | 优先 Boss，否则朝覆盖敌人最多的走廊；0.5 秒冲刺，伤害 ×25、必暴击、距离 ×10、宽度 ×5；无视地形，落点受阻时寻找附近空地；结束后额外无敌 2 秒。 |
| 陨石 | 3 秒内每 0.1 秒召唤一颗，共 30 颗，半径 ×3、伤害 ×10；落下延迟 0.5 秒，最后一颗落地前保持施放锁定，总计约 3.4 秒。 |

减速默认持续 2 秒，持续命中刷新；强行特性仍会移除附加减速。Boss 方向取最近存活 Boss。持续光环、地雷、炮台、回旋、冲击波、地面轨迹、扇形、属性增益八类暂不进入 Z 选招。

## 调试

进入单人局 → F2 →「Z 招式试玩」选择招式 →「替换为测试招式」→ 可生成测试敌群或 Boss → 收起面板 → F → 1。替换会清空当前局技能，自动授予并装备匹配 Z 石、回满生命。可用「Z 石立即就绪」反复测试；施放中禁止替换或重置。所有调试局不提交排行榜。

## 验证与限制

新增自动测试覆盖保存迁移与合并、Mega 互斥、同槽匹配、七类参数及伤害次数、方向选择、选招及释放无敌、死亡清理、落点恢复、联机视觉副本及道具转经验。联机副本仅播放视觉，伤害沿用原有权威结算，避免副本重复伤害；仍需真实双设备试玩验证网络延迟下的表现。

Z 石正式掉落来源、其余八类 Z 变化和最终平衡尚待后续设计；本版用于试玩效果。

# PokéSurvivor 开发与版本记录

## 仓库工作流

基于 JPTER78/pokesurvivor 开发，保留上游提交历史。`upstream` 用于获取原版更新，`origin` 用于保存我们的开发版本。后续每次完成版本迭代，都提交、创建版本标签并推送，确认远程同步成功。

版本号采用 `vMAJOR.MINOR.PATCH`：小修复递增 PATCH，兼容的新功能递增 MINOR，重大不兼容变更递增 MAJOR。标签与 `version.json` 的构建指纹用途不同：前者记录开发发布版本，后者驱动网页自动更新。

本地启动：

```powershell
Set-Location 'D:\GuguFiles\AIWorkspace\PokeSurvivor'
py -3.14 -m http.server 8000 --bind 127.0.0.1
```

游戏入口：http://127.0.0.1:8000/ 。源码调试入口：http://127.0.0.1:8000/dev.html 。

完成版本后执行：

```powershell
git status --short
git diff --check
# 核对并明确暂存本版本文件，再提交；不要包含其他工作或敏感数据。
git commit -m '描述本版本的具体改动'
git tag -a vX.Y.Z -m '版本改动与验证摘要'
git push --atomic origin main vX.Y.Z
git ls-remote origin refs/heads/main refs/tags/vX.Y.Z 'refs/tags/vX.Y.Z^{}'
```

`main` 与标签解引用后的提交 SHA 应与本地本版本提交一致。若推送失败，处理原因后重试，不重写已推送历史。

### v0.5.0 — 2026-10-15

- 实现用户本轮设计的沙隐、粗糙皮肤、心灵感应、引火、慢启动、湿润之躯、梦魇、多属性、胜利之星；重做火焰之躯并加强飘浮。细节见 `docs/ABILITY_DESIGN_SINNOH_UNOVA_KALOS.md`。
- 神奥 15 只五星宝可梦新增 20 枚勋章，合众比克提尼新增胜利之星，总计 42 只、63 枚。各地区独立保底与原物种概率保留；合众未设计物种仍抽出宝可梦，页面明确展示未全部开放及五星奖励保底。
- 沙隐复用轻金属的每层 +20% 移速、5 秒、最多 3 层加速；沙暴生效时立即及每秒增加/刷新，天气结束后按剩余时间消退。沙暴伤害免疫不影响其他天气伤害。
- 火焰之躯不再掷 30% 概率，接触受伤后对周围 120 范围施加击退与 5 秒灼伤，共用 1 秒隐藏冷却；保留既定灼伤总伤害与 Boss 击退豁免。粗糙皮肤朝攻击者发动等级 1 撞击，不占技能槽，不修改正常技能冷却。飘浮不主动引爆地面陷阱，其他单位仍可触发附近陷阱。
- 心灵感应匹配自身任一属性始终减伤 50%，实际扣血且存活后恢复 5% 最大生命，仅回血冷却 1 秒。引火由实际火属性伤害触发攻击 +50%／5 秒，重复刷新不叠加。
- 慢启动经验 ×0.7，按现有联机经验平均规则纳入团队计算；每次升级独立以 50% 概率连续选择两次，不额外升级、不递归判定。联机本地完成所有选择后才通知队伍完成。
- 湿润之躯在有效雨天清除/免疫所有现有玩家负面效果（陷阱、地形、天气减速），不抵消伤害；被气闸抑制时失效。梦魇对所有来源减速中的敌人每秒扣除 5% 当前生命，按现有伤害整数规则结算，多个梦魇不叠加。
- 多属性忽略属性克制表，天气倍率仍有效；全部伤害减免/增伤覆盖环境与玩家造成的持续伤害，联机伤害权威端只增幅一次。胜利之星统一提高自身非环绕投射物速度 30%，回旋镖保留原去程半径并提高返程速度。
- 调试伙伴/勋章列表自动包含新内容，增加同属性和火属性伤害测试按钮；保持默认关闭、仅单人调试及调试局不上榜规则。
- 验证：57 项自动测试及源码语法检查通过；构建、数据导出、SEO 生成通过。本地构建版浏览器验证神奥沙隐与合众胜利之星指定抽取、宝石扣除、沙暴加速三层、引火助燃 +50%／5 秒、慢启动同等级连续两次选卡与恢复战斗，以及合众未全部开放说明。修复实测发现的无天气空对象访问，并补充天气开始前/清除后的回归检查；最终构建（833183a82c）未出现 error 日志。
- 限制：真实双设备联机未实测；合众其余新特性和卡洛斯、形态特性等待用户设计。

### v0.4.0 — 2026-10-15

- 按用户设计实现城都、丰缘 20 只五星宝可梦的 31 枚特性勋章，总计 26 只、42 枚。压迫感、精神力、紧张感、多重鳞片复用既定规则；每只只装备一枚。
- 开放关都、城都、丰缘特性抽卡；共享宝石余额，各地区独立保底，维持各物种原抽取概率、重复勋章返还 300 金币和普通宝可梦抽卡行为。
- 天气特性首次于 40 秒触发，之后每 40 秒召唤 20 秒天气；气闸抑制全场天气伤害、减速、属性倍率和雾天暗角，但天气继续计时。确实无天气时，气闸暴击倍率由 1.5 提高至 2.25。
- 再生力在无伤 5 秒后每秒恢复 5% 最大生命；自然回复开局免疫陷阱/地形/天气减速，受伤失去免疫，无伤 20 秒恢复。实际扣血（含环境和生命宝珠）会重置无伤计时，闪避及无敌挡下的伤害不会重置。
- 懒惰按每四次有施法冷却的技能触发一次：第四次自身冷却翻倍并恢复 5% 最大生命；融合槽内每个技能分别计次，持续环绕不计作反复施法。
- 威吓命中施加 3 秒害怕，伤害降低 20%，刷新而不叠加；普通攻击、飞弹和预警范围攻击均接入。天恩每次有效伤害有 10% 概率等概率施加减速/普通灼伤/中毒/静电/紧张/害怕，伤害与击杀归属包含玩家造成的持续伤害。
- 自信每层 +10% 攻击、3 秒独立计时，最多 5 层，满层新增时替换最早到期层；轻金属每层 +20% 移速、5 秒共用计时，最多 3 层，重复刷新。两者与同属性技能 buff 的百分比加成相加。
- 恒净之躯延长技能增益与祭坛效果 50%，不延长受伤无敌或永久强化；结实在致命伤害时保留 1 HP 再回复 50%，仅实际地表阶段变更刷新次数，进出裂隙均不刷新；冰冻之躯仅在未被气闸抑制的雪天回血。
- 飘浮穿越实体墙壁/障碍，重叠期间禁止新施法并清除环绕弹，已发出的普通投射物与已放置场地仍继续；活动技能冷却继续。起止各减速 70% 持续 0.3 秒，持续穿越减速 50%，两档不叠乘。裂隙与审判场地边界仍受原有夹限约束。
- 增加特性状态 HUD、害怕图标和调试天气/受伤/致命伤害按钮；修复队友视觉投射物重复造成伤害。联机扩展天气请求、害怕状态、击杀归属和自信层数通知。
- 验证：`node --test tools/test_abilities.cjs`（43 项通过，包含全部新特性、分区卡池、存档兼容和联机协议模拟）；源码与构建产物语法检查、构建、数据导出、SEO 生成通过。本地构建版浏览器验证城都/丰缘指定勋章抽取及宝石扣除、飘浮穿越与移速状态、结实救命和地表阶段刷新、气闸天气抑制，浏览器无 error 日志。真实双设备联机尚未验证。

## 本分支调试

- 中文入口：设置 → 画面 → 语言 → 简体中文（中文浏览器默认选择中文）。
- 开发者开关：设置 → 开发者 → 开发者模式；启用后点击右下角「调试 · F2」或按 F2。
- 资源调试会修改当前本地存档，建议使用独立测试账户或游客。游客退出后不保存。
- 视野范围：F2 面板顶部拖动滑块，1× 为正常视野，1.5× 为默认宽视野，2× 显示两倍宽高的世界范围。
- 货币增减：金币、单抽券、十连券、特性宝石各有数量输入框和 −/＋ 按钮；单次输入范围为 1 至 1000000000 的整数。
- 测试同步：选择梦幻、装备同步勋章，进入游戏后点「自身减速 3.5s」。
- 测试宝石奖励：进入游戏，点「开启裂隙战斗」，再点「击败裂隙 Boss」，胜利后宝石增加 1；胜利重复通知不会重复发奖。
- 指定勋章仍消耗宝石；获得重复勋章返还 300 金币。
- 常规构建需要 Node.js/npx；SEO 生成脚本需要 Python 3.12 或更新版本（本机使用 `py -3.14`）。

# 全世代 Mega 素材预览

版本：v0.7.0，2026-10-15。

从 PMDCollab/SpriteCollab 固定提交 `e7868e9a7f6b931d1fb826756a490d4633879d03` 导入现有素材。范围扩展至全部世代：导入所有 `sprite_complete >= 1` 的 Mega 形态，保留旧版 4 个部分完成的预览。排除改色/画法替代槽、袋兽宝宝、暗影及原始回归形态。

共登记 96 个独立形态，36 个基本达标形态全部加入；另保留旧版 4 个部分完成形态，共 40 个可预览。其余 56 个未加入：54 个尚无局内动画，超级头巾混混与超级摔角鹰人虽有部分动作但未达本次标准。完整逐项列表见 [MEGA_CATALOG.md](MEGA_CATALOG.md)。

40 个可预览形态中 36 个有异色素材，共 532 张 PNG，约 4.76 MiB。超级恰雷姆、超级盔甲鸟、超级班基拉斯和超级达克莱伊暂缺异色局内素材。

## 如何试玩

1. 设置中开启开发者模式，按 F2 或点击“调试”打开面板。
2. 在“Mega 素材预览”选择形态，点击“选择对应本体（局外）”。
3. 开始单人游戏，再打开面板，点击“应用 Mega 外观（局内）”；有素材时可勾选异色。
4. 正常移动和自动施法即可观看效果；可用“测试动作”分别播放待机、行走、攻击、远程、蓄力、受伤和倒下动作。
5. “恢复本体外观”可随时还原；关闭开发者模式或进入联机会还原；下一局也从本体外观开始。

这里只导入视觉素材并提供调试入口。数值、属性、特性、已学技能、碰撞半径和存档物种编号沿用本体，不加入抽卡、进化石、正式变身条件、持续时间或额外战斗加成。预览只限单人调试，使用后本局不提交排行榜。

## 加入和缺失清单

[完整清单](MEGA_CATALOG.md)按世代逐一列出已加入的 36 个达标形态、保留的 4 个部分形态与尚未加入的 56 个形态。开发者列表同步显示“基本达标”“完整级”“未达基本标准，旧版保留”“已有部分动画，未达基本标准”或“暂无动画素材”。未加入形态不能选择。

## 动作完整性

所有可预览形态均使用 Mega 自身素材。缺少某动作时，在同一形态中按现有渲染约定借用兼容动作，文件及元数据明确记录源动作。

- 超级蜥蜴王：现有待机、行走；攻击、远程、蓄力、受伤、倒下借用待机。
- 超级风铃铃：目前仅待机，行走及战斗动作均借用待机。
- 超级呆壳兽、超级巨牙鲨等也有部分动作借用；完整逐项映射见 [MEGA_ASSET_CREDITS.md](MEGA_ASSET_CREDITS.md)。
- 其余多数形态缺少独立倒下动作时，借用自身受伤动作；不据此声称源素材已完成全部动作。

## 来源、重新导入与验证

- 素材文件、源目录、画师、原/异色动作映射及 SHA-256：[manifest.json](../assets/mega/manifest.json)。
- 署名与源目录：[MEGA_ASSET_CREDITS.md](MEGA_ASSET_CREDITS.md)，总署名入口为 [CREDITS.md](../CREDITS.md)。
- 导入脚本：`tools/fetch_megas.py`，需要 Python 3 和 Pillow；当前使用 Codex 随附、已安装 Pillow 的 Python 运行。普通 `py -3.14` 环境若未装 Pillow，需先准备该依赖。
- 离线资源验证：`python tools/fetch_megas.py --validate`，检查所有 PNG 完整性、尺寸、帧数、时长、锚点和校验和。
- 渲染与回归测试：`node --test tools/test_mega_preview.cjs tools/test_abilities.cjs`。

自动验证覆盖全部已导入形态及其异色版本的七类动作、八个方向，验证取帧范围、渲染器可加载性、全世代对应本体应用/还原、仅改视觉、调试权限与联机还原。浏览器验证结果记录于 [DEVELOPMENT.md](DEVELOPMENT.md)。

# 远征经济配置与兼容决策

运行参数统一来源为 `config/economy_config.json`。源码页面通过 `G.EconomyReady` 加载；标准构建直接嵌入该 JSON 的快照，使离线版与构建指纹保持一致。改表后应重新构建。训练家经验独立于战斗中的队长经验、属性成长及升级果子。v0.43.0-alpha.19起，队长与队员每级自动成长均读取 `levelGrowth`：基础生命、双攻各1%，不自动增加双防、敏捷、耐力、速度；果子、装备、技能及特性等独立加成保持各自规则。

## 本轮明确保留的规则

- 按用户后续回复，商店仅有五个宝可梦邀请位，不落地道具货架或道具买卖。扩容、训练家执照以商店服务按钮提供。文档的道具价格、回收比例与星级倍率原值保留在配置中供后续迭代，未启用。
- 两合一升星和既有双攻/生命倍率不变。1/2/3星消耗1/2/4张卡；出售返池张数据此计算。用户要求售价继续使用文档原表，因此高星出售可超过实际合成成本。这是本轮明确保留的已知经济套利点，尚未作为数值平衡完成的版本。
- Mega暂不接入，既有局外超进化系统继续沿用原规则；不会新增无尽商店Mega商品或4星队员。
- 普通全清1件、精英获胜2件普通道具的上一版规则保留；排除BOSS道具和未许可/禁用道具。BOSS保留原奖励箱，另加金色属性徽章三选一。

## 运行结算

`js/systems/economy.js` 管理钱包、经验、等级阀门、每日结算和商店服务。`js/systems/unit-pool.js` 管理个人卡池。`js/systems/expedition.js` 负责把这些服务接入既有日程、商店、战利品与无尽循环。

开局金币为0、训练家1级。工资、基础利息与连胜/逆境只在战斗生还后结算；普通战超时生还仍是一次战斗胜利，全清额外道具另行判断。剩余血量以队长结战时HP比例为准，不计随后回血。基础利息使用开战时快照，所有拾取物（包括打开箱子后新生成的掉落）收集完成后，一次结算工资等收益与经验，按天防重入。v0.43.0-alpha.18起，配置 `combatGoldDrops=false`：远征不生成金币或额外宝藏掉落，BOSS箱与地形等来源也统一拦截。旧掉落记录不进入战利品，结算输入中的掉落金币忽略，`inWaveDrops`保持0。击杀本身不额外直接发放远征金币；工资、基础利息、连胜/逆境及特性收入不变。

非战斗日仅发配置中的训练家经验，不改变压制连胜。经济特性的每日工资/利息也限制在战斗日，叠层特性的每日触发仍保留，其他经济特性继续使用特性目录的数值。此次未全面重新平衡特性收益。

第1—3轮最高9级，96XP可保留等待第4轮开放10级。战斗中的队长升级仍按既有规则增长属性；形态自动进化改由训练家5/8级触发，当前已选择的队长形态不回退，分支进化仍随机。单次加经验支持连续跨级，已达当期等级上限时不能继续购买经验。

每次进入商店自动刷新并赠送一次免费刷新；锁定跳过进店刷新，保留已购空位，升级与购买经验不刷新。手动刷新会解除整店锁定，优先消耗本次免费次数，其次特性免费次数，最后扣金币。BOSS后的商店不推进天数、不重复日结。

卡池按进化家族初始化。货架上的未购买卡也占库存，刷新时先退池再抽。各费用先按等级概率抽取，再按剩余库存抽家族；耗尽或已追满的费用候选为空时，其权重在其余非空费用间重新归一。若所有可抽费用为空，货架显示空位，不扣不存在的卡。持有3星停止抽该家族，出售后解除屏蔽。

普通/精英战后捕获和野外遭遇从同一卡池抽取；精英使用训练家等级+1（最多10）的概率。放弃领取退池，领取且仓库满时按1星原价折金币并退池。野外优先寻找已激活属性/职业的候选；必要时该保证位放宽费用概率，前提是该家族卡池仍有库存且未被3星屏蔽。没有任何合格库存时无法保证数量或匹配。

金色属性徽章的首轮定义是对应属性羁绊生效数+1，可叠加且只影响当前远征；不会给队员额外标签。BOSS结束后必须完成三选一，再继续升级/路线。第60天通关弹窗保留结束与继续入口，选择继续后进入第4轮免费商店。

v0.43.0-alpha.17起，商店以外的事件不消耗金币。技能修炼（含第4轮超限）每次事件免费选一项；专精、联结、技能突破仍需要长征之路权限卡。超限对所选伤害招式每次增加5%，按次数相加。商店招募、刷新、购买训练家经验、扩容与执照仍按原价格扣费。

宝可梦训练室与技能修炼各占原权重的一半（1.5/1.5）。特训提供一条当前等级经验，遵循宝可梦经验倍率，并正常结算升级选择；不给训练家经验。孵蛋可选队长或队员，记住当时家族，远征总日数满10天后的日终自动尝试加入一星基础形态，跨周期有效，亲本离队仍有效。满仓且不能合成时保留待领取，可在路线页查看进度并重试；孵化入队照常触发两合一。

长征之路卡包新增一张永久 `training:pokemon-breakthrough` 权限卡，原有三张权限保留。训练室突破仅作用于未满3星队员；先选目标，再选不同的同星蛋组材料与技能类别材料，最后明确执行。队长不作为目标或材料，但可以孵蛋。一次训练室选择突破后可重复突破，不能再切换特训或孵蛋。材料只移除、退还其实际卡池份额，不发放生金币或放生特性奖励；目标保留真实卡池份额，升星读取对应形态属性与技能等级，并遵循随机分支和自动合成。

成员新增 `poolCopies` 记录实际从商店池带出的份额，合成时相加。孵化副本份额为0，突破升星不凭空增加份额；以后出售只退还真实份额，避免把繁殖与跨家族材料转成额外商店库存。出售金币仍按星级原表，沿用上一版已记录的套利取舍。蛋与训练室选择只属于当前远征，结束本局后不带出。

## 必要验证入口

`node --test tools/test_economy.cjs` 覆盖规范的工资、利息、连胜、经验、卡池、出售与无尽核心断言，其中合成验收按用户指定的两合一调整。`node tools/qa_economy.cjs` 在独立内存SQLite和隔离Edge中验证页面流程，截图写入忽略目录 `tools/cache/`。浏览器需已有 `tools/cache/browser-qa/node_modules/playwright` 与本机Edge。测试不访问真实玩家数据库，不代表长线平衡性评估。

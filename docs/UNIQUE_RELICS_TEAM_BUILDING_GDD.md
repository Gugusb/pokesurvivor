# 远征唯一道具设计

- 文档版本：1.2 草案
- 整理日期：2026-11-28
- 玩法基线：远征版本 v0.43.0-alpha.79
- 状态：候选设计库，尚未实装；数值为首轮试玩建议。

## 设计范围

围绕“宝可梦个体与队伍构筑”“生命、防御与续航”“PP、技能槽与技能养成”共26个维度，为各元素分别设计局内唯一遗物。第一部分94件（编号1—94），第二部分68件（编号95—162），第三部分72件（编号163—234），合计234件；其中编号59为暴击节奏补充候选，其余233件对应原维度拆分。一／二／三星、奇数／偶数位置、刷新／叠加、近战／远程、属性／职业偏向等并列元素分别处理。

“指定物种”“指定品质”“指定伤害属性”等可选参数使用一件可指定对象的道具，不为每个取值重复建立条目。本文件归档逐维度展开的候选，不替代此前覆盖全部远征机制的30件唯一道具与10种无限道具初案，也不表示所有候选将同时进入正式奖励池。

## 通用规则

- **局内唯一：**每局每种最多获得一次，整局结束清除；消耗型使用后也不重新进入本局候选池。
- **属性结算：**百分比属性增益进入对应加成区，不因反复计算产生复利；比较最高、最低或差值时，不包含本道具自身造成的加成。
- **条件快照：**队伍构筑条件通常在开战时确定；存活数、当前生命等明确实时条件按战斗状态更新。
- **指定对象：**选择类道具可在战前改选，但不能因改选重复领取资源或触发一次性收益。
- **时间口径：**冷却与持续时间使用战斗游戏时间，暂停不推进，多倍速一致。
- **生命与护盾：**宝可梦生命、宝可梦白盾、小队生命、小队护盾分别结算。治疗和白盾遵守既有上限；属性重算不等同治疗，不能通过换位或改选反复补满生命。
- **身份口径：**品质为1—5，星级为1—3；家族指同进化链。羁绊原本的去重、激活与受益范围保持不变，除非道具明确写出修改。
- **权限范围：**不提前开放段位、卡包尚未解锁的机制；没有对应机制的道具不主动推荐。
- **触发边界：**效果引发的转移、分享和资源返还，不得递归触发自身。免费行为不返还未实际支付的资源。
- **记录口径：**真正参加过战斗、个体首次登场、每店／每日／每周期次数均需独立记录；拖动卡片、取消操作、保存续玩不能重置记录。

## 道具池取舍建议

分支选择、编队位置、轮换和材料传承类更适合作为有辨识度的唯一遗物。直接提高属性的候选需控制占比，并与现有道具去重。

正式选入时，应将作用相近的候选放在一起比较：例如新星披风与蜕变糖衣、出勤臂章与首秀彩带、熟客名册与团聚合影框。不同方案可以竞争同一设计位置，不必全部同时上线。

本轮仅形成设计文档，不调整正式道具池、掉落、解锁、数值、存档或游戏版本号。

## 生命防御与续航通用规则

本续篇逐项覆盖原清单的7个维度。双防拆成物防、特防；近战／远程、刷新／叠加、普通／精英／BOSS剩余数量、全歼／无伤补盾分别设计。复活部分的“队长死亡流程单独处理”是通用边界，不额外计作一个道具元素。

- **作用对象：**“成员”包含上阵队长和队员，不包含候补；“队员”明确排除队长。“小队生命／护盾”仅指远征战略资源，不指宝可梦个人血量／白盾。
- **实际失血：**受伤计数只认敌人或环境造成的实际生命损失，不计白盾吸收、自损代价、最大生命重算、分摊与延迟伤害的二次记录。连续无伤条件采用同一口径。全场无伤按每名参战成员的实际失血记录判断，不能用当前满血替代。
- **统计快照：**开战记录每名成员最大生命，累计受伤阈值以此为基准；单次受伤阈值、治疗与即时白盾以该事件发生前的最大生命为基准。历史最低血量比例只在本场真实受伤后更新，战后重置。
- **治疗口径：**全队为本道具受益范围，不表示一次触发治疗所有人；单个目标、邻位或全队分别按条目说明处理。治疗不能复活，溢出与延迟治疗不能跨战无限储存。
- **治疗限速：**本续篇新增的战斗治疗统一纳入每名目标每游戏秒3%最大生命的共享治疗额度；允许兑现的排队额度不因限速截断。明确延迟治疗在结算前处理，到结算时目标已倒下则丢弃，不带入下一战。战后治疗单独结算且不触发战斗治疗连锁。
- **白盾限制：**本续篇新增白盾与其他白盾共用40%最大生命上限，不因拆分为独立盾层而绕过。盾到期、自行消耗、属性重算不算被敌人打破；一次伤害不能循环触发多次破盾收益。
- **承伤顺序：**属性／防御和减伤、适用的单次伤害上限先确定本次伤害，再处理本续篇的延迟／分摊，最终消耗各目标白盾与生命。后置伤害不再次享受原攻击的减伤或触发受击连锁。特殊减伤与无敌保留原有规则。
- **防止无敌组合：**建议新增百分比减伤彼此相乘并接入项目既有总减伤限制，不能直接相加到100%；正式实现时需核对现有各来源结算。本续篇不扩大既有无敌时长上限。
- **非递归收益：**治疗转移、延迟补疗、治疗转盾、反伤和分摊不再次触发本续篇的派生效果；只能使用普通技能等明确原始来源触发，不能形成相互复制。
- **复活与失败：**额外复活次数默认只作用队员，不赋予队长自动复活。明确的致死保护必须在死亡判定前消费，不能在已经失败后恢复游戏。不给小队生命设置隐式50点等回填底线。
- **小队扣血顺序：**剩余敌人原始伤害→来源修正→当前周期单场伤害上限→明确的结算减伤→小队护盾→小队生命。最终防致死条目只在最后一步介入，不能改变全歼／击杀评价。
- **次数与存档：**每场、每周期、整局次数及待兑现效果均按既有节点存档规则保存；重开界面、改编队或读档不补发。获得前的战斗、失血、护盾耗尽等不追溯计数。

## 生命防御候选的组合与落地检查

这68件是对元素逐项展开的备选方案，不是要求全部同时上线。生命、防御和补给叠加会显著改变战斗压力，筛选时应先比较相近用途，再选择有限数量进入道具池。

| 组合或机制 | 落地前需要确认的内容 |
| --- | --- |
| 完好封蜡与静息贝壳 | 都保护下一次直接伤害，需决定是否同一候选组；不能各自按减免前伤害重复结算。 |
| 韧性缝补包、裸露警报器与事故气囊 | 同一次受伤可能多项发盾，应共用白盾上限，保护不得回溯到已经结算的伤害。 |
| 备用药棉、复诊闹钟与凝胶分离器 | 原始治疗只处理一次转换；明确有效治疗、溢出、转盾和额外治疗顺序，禁止派生收益互相复制。 |
| 耐候盾膜、续封蜡印与夹层护垫 | 需要可靠区分原盾、刷新、叠加、丢弃余量与独立到期时间；不能每次刷新都无限续期。 |
| 能耗护符、紧急糖片与碎盾铃 | 需要沿用PP实际消耗与技能槽规则；新增临时PP不能反向制造“实际支付金币”等无关触发。 |
| 缓冲液囊与互援牵绳 | 实现前固定与已有延迟／分摊特性的先后次序，总量守恒；待扣伤害结算前扣清，不能靠过场抹除。 |
| 限压阀与最后一针 | 前者是单次伤害封顶，后者是一次致死保护；先计算伤害，再判断是否真正需要消费致死保护。 |
| 备用苏生签 | 各家族复活次数、等级门槛、延迟和共享次数需走原接口；不让没有复活能力的队员凭空复活。 |

| 行军轮休券与断后撤退绳 | 先完成扣血及合法防致死，再处理胜利恢复；已经判定失败不能靠后发治疗撤销。 |

治疗和护盾效果应在界面上区分“个人生命／白盾”与“小队生命／护盾”；低血提示展示实际触发条件、次数和恢复量，不用模糊的“自动恢复至安全血线”。

## PP技能槽与技能养成通用规则

本续篇覆盖原清单第18—26维度，共72个元素。“偏向已有属性／职业”分别设计；“换招保留突破与专精属于强规则改动”以及“减免三星材料强于减免金币”是设计边界，不额外计作元素。本轮不给换招增加默认保留专精或突破的权限，也不直接降低突破材料星级。

- **技能范围：**普通技能指成员正常掌握、满足施放条件的非Z招式。复制、反击、额外弹幕、羁绊派生攻击不作为新的普通施法计次。已突破技能仍可作为普通招式使用，但不会因此绕过专用伤害预算或次数限制。
- **自然恢复：**近战／位移成员离队期间仍禁止自然恢复PP；提高自然恢复速度不会绕过这个条件。明确的额外恢复或临时PP允许生效，但不能让归队等待充满的成员提前索敌、攻击。
- **资源分账：**普通PP属于具体技能；临时PP、既有超额储备使用各自账本。临时PP不因任何道具变成永久最大PP，既有要求下场结束失效的激素果实额度不跨战保留。
- **比例口径：**招式PP比例为其普通当前PP除以普通最大PP，不把临时PP算入“满PP”。单技能队员使用其招式；队长相关条件按正在处理的招式计算，不能把多个槽的PP任意拼成一个比例。
- **扣费记录：**每次成功施法记录原始费用、折扣、免耗、普通PP支付、临时PP支付与代付。未成功施法、被取消、无目标而未发动的操作不扣次数，不反复刷新随机判定。
- **减免与返还：**本续篇普通折扣最低消费1点；明确免耗／代付另按次数额度处理。同一次施法的累计返还不能超过其实际支付，退回原支付来源并遵守容量，溢出丢弃。维持光柱等持续扣费与启动费分账，默认不享受“下一次施法免耗”。
- **防循环：**恢复、返还、临时补给不计作施法、支付、击杀或再次恢复的原始触发。由道具补发的PP不触发本续篇的“额外恢复增幅”，免耗施法不产生实际支付进度。
- **计次与储存：**未另注明的战斗计数每场清零；待使用优惠最多保留1份，冷却期间不积攒无限待发效果。明确的下一场资格、专精次数和养成记录则按本局存档保存。
- **冷却底线：**冷却／前后摇调整只处理本来存在的时长，不制造负冷却或重复施法；不重置环绕补圈，不缩短Z充能。额外推进有上限，未解锁后台冷却资格的槽不会自动获得持续后台计时。
- **技能槽：**切槽类默认只作用队长。有效切槽必须切至不同槽并完成一次正常施法；原地连点、来回切换但未施法不计数。需要在首次施法前生效的起手冷却推进，在真实切槽时立即消耗共用冷却，不能因未施法退还或反复空切推进。空槽只计算已解锁槽，不把未来槽位当空位。
- **候选规则：**候选数量、重抽、权重和预留都只从当前合法、已解锁且未被禁止的池内生成，除条目199明确扩展的一招外，不擅自扩大合法池。无重复优先；不足时展示实际数量，不复制选项，不暗中返还选择次数。
- **学习权限：**队长完整可学列表不会因为“候选+1”创造额外招式；此类道具只作用真正随机抽取的普通学习／换招选项。既有三选或五选不减少，叠加额外候选统一最多6项，不影响训练家潜能或升级果实。
- **事件操作：**重抽、预览、锁候选不消耗正式执行机会；成功学习、升级、换招、专精、突破、联结仍各按当前规则执行，每次技能修炼事件只能完成一项。不能以取消操作重抽金币、材料或奖励。
- **换招继承：**原技能等级照常保留，突破与专精仍清空，职业随新技能变化。新招式不能继承旧招式的专用折扣、一次性施法奖励或满级认证，明确标注绑定个体的效果除外。
- **专精费用：**保留初始5G及每次涨价50%的基础规则。优惠作用于最终本次应付费用，最低1G；原价序列、专精次数和折扣分别记录，不能拿折后价继续递推造成无限复利折扣。
- **突破材料：**目标招式满级且有合法突破方式；材料为另一只合法三星宝可梦，属性匹配技能属性，属性提升招式使用一般系材料。队长不能被消耗，候选展示不意味着免材料，所有动作以材料真实消耗且突破成功为准。
- **实际融合：**按真实已融合技能槽计数，不按未用联结次数计数。槽内技能、类型、支付和施法各自记录；整槽奖励与单招奖励分开，不能把一次融合槽施放重复计成多次切槽。

## PP技能养成候选的组合与落地检查

这72件按元素独立展开，部分与前文已有候选服务同一需求，正式入池时应作为备选比较。例如加页招式册与专精旁听证分别改善不同选项池，而试招修订橡皮与局部改题笔功能接近，不应简单一起加入来叠加重抽次数。

| 组合或机制 | 落地前需要确认的内容 |
| --- | --- |
| 扩口水囊、备用储能隔层 | 当前普通PP、最大PP和超额储备的存储结构与容量边界；没有储备机制时不能提前开放。 |
| 补给增压嘴与所有返还道具 | 区分自然恢复、技能／特性补给、道具补给和退款，记录来源并屏蔽派生递归；满PP不能累计无限小数额度。 |
| 节流、返还、免耗与代付 | 固定折扣→免耗额度→实际支付／代付→事后返还的顺序；总返还不超过实际支付，免费次数不能被取消动作刷出。 |
| 光柱维持与融合槽施法 | 启动和维持分账；整槽施放与槽内单招计数分开。环绕命中、光柱每跳和炮台射击不计新的成员施法。 |
| 低PP、见底与满PP | 按技能普通PP判断，确定施法前／后的快照；临时PP不使满PP条件永远成立，不干预近战归队禁攻。 |
| 后台冷却与切槽推进 | 不给未解锁能力的槽增加持续后台计时；同一次切换的多个推进按共同剩余值结算，不能负冷却或额外出招。 |
| 延时蜡芯 | 明确普通正向增益与非召唤持续区域白名单、原跳伤间隔和到期动作；不延长敌人控制、无敌或Z预算。 |
| 联招排序卡 | 现有融合是否整槽原子支付、各招失败及目标选择的规则需要先核对；新增顺序必须明示，不能导致扣费后无故不发动。 |
| 同行招式抄本 | 定义队员突破技能回溯到基础招式的映射；队长专属禁用、已有槽数、卡包权限始终优先，不能从队员复制完整培养成果。 |
| 候选数量、权重与避重 | 单一抽取流程内统一处理；不足时有确定回退，不重复、不卡死，也不减少原有五选一收益。 |
| 职业推演板 | 基础标签及现有详情始终可查看，道具只提供额外构筑对比与激活奖励；不能把必要基础信息改成付费权限。 |
| 研修方向标与交叉研修印 | 先为现有专精建立固定的威力／续航／范围等方向归类；无方向或不可选条目不能强行塞入候选池。 |
| 工坊小额抵券与涨幅缓冲单 | 原价序列独立保存，每次折扣后至少支付1G；优惠不返金币、不影响材料、不把折扣当投资本金。 |
| 跳级训练凭条 | 仅在本来合法的队长升级操作中消耗，成功后才计一次事件；队员1／3／5级仍遵守星级规则。 |
| 学分承接章、开题奖章与深修打卡册 | 等级继承与专精清空是原规则，奖励是新增部分；跨进化个体记录保留，换招不能重复刷首次奖励或转移旧招式优惠。 |
| 三星培育履历与后备素材夹 | 真实升星历史、上一战候补状态和个体ID需随存档保存，临时拖动、同族替换或反复读取不能伪造材料资格。 |
| 联结登记环与多芯联结座 | 只计算实际融合内容；联结前后重算不会永久积累属性，不以可用联结次数替代融合槽数量。 |

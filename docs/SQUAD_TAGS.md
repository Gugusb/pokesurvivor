# 小队标签与羁绊设计清单

当前版本 v0.43.0-alpha.5 共 48 个标签：属性联结 18、种族天赋 15、职业羁绊 15。以下为现有数据与显示名称，效果留待设计。

- 属性与蛋组随当前宝可梦形态变化；双属性、双蛋组分别贡献各自的标签。
- 职业标签由实际技能类型决定，不是技能的伤害属性；「属性提升」指 buff 类招式，不包含升级时吃的果子。
- 当前页面统计队长及上阵队员，每只伙伴对同一个标签最多计一次；队长多个同类技能不重复计数。多只相同宝可梦分别计数。倒下的上阵队员仍在统计中，候补不计入。
- 标签目前只有展示和统计，尚未产生羁绊奖励；现有队员支援特性是另一套已实现的效果，不等同于标签羁绊。后续阈值、同类叠加、作用目标和倒下后是否保留等规则均可另行设计。

# 队员固定初始技能 · v0.43.0-alpha.9

## 数据与适用范围

导入提供的fixed-skills.js表，运行时数据位于js/data/fixed-skills.js。解析时仅提取数字图鉴编号与技能ID，未执行外部JavaScript；原始来源SHA-256记录于G.FIXED_SKILLS_SOURCE。966条记录恰好覆盖当前966只宝可梦，每个技能ID有效，且属性属于该形态自身属性。

- 仅替换远征队员默认招募技能与商店商品的初始技能；队长起手、学习池、升级和其他旧模式不变。
- 商店先决定最终形态及阶级，再取该形态表内技能。购买时使用已展示的技能，高阶商品沿用2/5/超武的阶级成长。
- 战后领取与直接招募统一经过Member构造规则；显式传入的合法技能仍可使用，保留修炼、测试入口及已展示商品的一致性。
- 技能修炼可从原有合法技能池更换队员招式，保留阶级。合成仍保留被保留队员的当前技能，不重新套用默认表；包含此前修炼的招式。
- 默认表不会改写账号收藏或存档，也不会恢复关闭浏览器前的整局队伍。

## 表内分支差异

按提供的数据保留以下差异，不擅自给所有分支强制指定一个技能：

| 家族 | 表内差异 |
| --- | --- |
| 喵喵/猫老大与喵头目 | tackle / metal-claw |
| 伊布各进化 | 各自使用quick-attack、bubble、thunder-shock、flamethrower等表内技能 |
| 狃拉/玛狃拉与大狃拉 | hail / toxic |
| 太阳珊瑚与魔灵珊瑚 | rock-slide / hex |

项目的进化数据将部分地区分支连接至同一基础编号，但其属性不同；固定初始技能以每只宝可梦的表项为准。普通家族及拉鲁拉丝等共同属性分支仍保持统一。

## 验证

单元回归覆盖966条记录、有效技能/属性/合法池、普通家族与四组分支、队长不变、各阶固定招募、修炼技能在合成进化后保留。网页验证使用隔离SQLite账号，分别检查队长妙蛙种子藤鞭、队员/商店剧毒，以及修炼回藤鞭后合成为三阶妙蛙花仍保留招式。完整验证结果见DEVELOPMENT.md。

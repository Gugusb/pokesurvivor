# 原作道具设计表

交付表格：`outputs/items-20261030-2d8e9c47/宝可梦原作道具设计表.xlsx`。

主表四列为“道具名、道具描述、道具功能、道具等级”。后两列故意留空，黄色底色便于填写。本轮不把表内道具自动加入游戏；待用户填完后再按设计转为特殊道具。

## 数据范围与来源

按 2026-10-30 取得的 [PokéAPI CSV 数据](https://github.com/PokeAPI/pokeapi/tree/master/data/v2/csv) 整理，原始 `items.csv` 2223 条，同名合并并剔除神石与奇异球占位记录后保留 2142 项。涵盖公开资料库已收录的主系列携带道具、回复药品、精灵球、树果、招式机、重要物品、食材及野餐用品；不宣称覆盖所有外传作品。

1490 项采用最新可得中文游戏描述，49 项使用功能摘要，603 项在资料缺少中文原文时使用分类用途摘要，摘要不冒充游戏原文。旧世代缺少正式中文记录时使用整理译名并保留英文标识。资料库“未使用数据”分类中的历史特殊条目保留并在映射页提示需确认正常入包情况，供设计参考；不是所有参考条目都能在正常游戏流程取得。不同版本的原效果可能改变。

“来源与映射”页保留名称、全部原始编号、英文标识、分类、描述类型、版本组和 API 链接。后续导入按名称及原始编号识别，不依赖用户排序后的行号。没有为用户预填游戏效果或道具等级。

## 文件验证

使用随 Codex 提供的 Artifact Tool 生成 Excel；表格筛选、冻结表头与首列、中文换行和输入色标已检查。主表 2142 条、四个指定列正确；两个设计列共 4284 个单元格全部为空，未包含公式错误。检查了 Excel XML 的记录数、冻结窗格及两个原生筛选表，并渲染查看排版。

# v0.2.0 特性、宝石与勋章设计

本版本按用户逐只确认的效果实现。原版特性仅作为设计参考，游戏内效果以下表为准。

## 特性与独立勋章

| 宝可梦 | 勋章对应特性 | 游戏内效果 |
| --- | --- | --- |
| 急冻鸟 144 | 压迫感 | 周围敌人攻击频率降低 20% |
| 急冻鸟 144 | 雪隐 | 本版本常驻。远程攻击有 10% 概率闪避，闪避后恢复 5% 最大生命；回血隐藏冷却 1 秒，闪避不受此冷却限制 |
| 闪电鸟 145 | 压迫感 | 同上 |
| 闪电鸟 145 | 静电 | 受到接触伤害后，攻击者静电 2 秒：减速 10%，该攻击者对自身的接触攻击有 25% 概率失败 |
| 火焰鸟 146 | 压迫感 | 同上 |
| 火焰鸟 146 | 火焰之躯 | 受到接触伤害后有 30% 概率使攻击者灼伤 5 秒；每秒一次，总伤害约为自身一发火花火球的伤害 |
| 超梦 150 | 压迫感 | 同上 |
| 超梦 150 | 紧张感 | 攻击命中后给目标施加 3 秒紧张状态，受到的治疗降低 50% |
| 梦幻 151 | 同步 | 自身被减速时，将本次受到的减速幅度反射给全部敌人 3 秒；隐藏冷却 3 秒；所有敌人受到的减速幅度乘以 1.1 |

共九枚勋章，标识是 `图鉴编号-特性`，如 `144-pressure` 与 `145-pressure` 独立。

- 每只同时只启用一枚已获得的勋章，亦可选择不装备；对局开始时读取装备，对局中不更换。
- 首次抽中某只的勋章且该物种尚无装备选择时自动装备，之后可在特性页或图鉴详情切换。
- 拥有宝可梦不等于拥有勋章，获得勋章也不赠送对应宝可梦。

## 实现约定

- 压迫感作用半径采用 240 世界单位，多个光环不叠加。攻击冷却以 0.8 倍速度推进，不改变敌人行走速度或已发出的弹道。
- 静电在实际受到伤害后施加，不取消首次接触伤害。再次施加刷新至 2 秒，减速不叠加；攻击失败不触发「受伤后」效果。
- 火焰之躯以触发时火焰鸟当前火花招式的单发基础伤害乘自身攻击倍率计算，未学习火花时用一级火花。忽略目标属性和暴击，每秒结算总额的 1/5，整数结算存在少量取整差异。重复施加刷新持续时间，保留下一跳时间。不添加原版灼伤的物理攻击减半效果。
- 紧张感重复命中刷新至 3 秒；包括目标自我治疗及其他单位给予的治疗，不影响护盾或最大生命变化。
- 同步反射当前实际减速（含陷阱、天气及地形），持续减速期间每隔至少 3 秒可再次反射。全局减速增强只乘一次，最终减速上限 95%，防止速度变负。
- 敌方投射物、远程光束及远程法术范围攻击归为远程；接触、冲撞、踩踏和跳跃落地归为接触。熔岩、地面陷阱和环境伤害不触发接触/远程特性。
- 联机消息同步装备特性、静电/紧张计时、远程施加状态与同步反射；敌人生命和移动仍由主机处理。真实双设备联机尚未验证。

## 宝石与特性抽卡

- 新存档初始赠送 10 枚特性宝石；旧存档迁移时赠送一次，不因再次登录补发。
- 每击败一个裂隙 Boss 获得 1 枚宝石；离开或失败不发奖，重复胜利通知不重复发奖。
- 复用宝可梦抽卡页面和转轮动画，在两个模式间切换；特性池暂时只有关都。
- 单抽消耗 1 枚，十连消耗 10 枚。道具余额、抽数统计及保底独立于普通抽卡。
- 沿用 1★45%、2★30%、3★17%、4★6.5%、5★1.5%；十连至少一项 4★或以上，第 70 抽保底 5★。
- 各物种保持原概率；抽到五只支持特性的传说物种时，在其对应勋章间等概率选择。其余仍为原宝可梦奖励，包括五星快龙。
- 勋章没有异色版本，重复返还 300 金币；普通宝可梦仍沿用原有异色与重复返币规则。

## 中文和开发者开关

- 用户提供的 `PokeSurvivor-PC/combined.js` 中的 3281 条显示文本通过 `tools/import_zh.js` 提取，未执行来源脚本。中文使用游戏原生语言系统，并补充特性系统词条。
- 设置 → 画面 → 语言可选择简体中文；网页与 Canvas 文本均翻译，保留英语和西语。
- 设置 → 开发者打开开关后，F2 或右下角按钮显示调试工具；默认关闭，仅用于单人。工具修改当前本地存档；调试局不提交排行榜。
- 此分支默认使用本地存档，后续云功能应连接独立 Firebase 项目。

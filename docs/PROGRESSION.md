# 难度、奖牌、挂机与倍速

v0.9.0，2026-10-16。

## 八星难度与通关

开始游戏右侧选择难度。新旧账号均从一星开始，旧版生存纪录不追溯颁奖。账号共享解锁进度，每通关当前最高可选难度后解锁下一星；不自动切换已选难度。四星完全保持旧版战斗数值。

难度 n 的敌人生命倍率 `1.05^(n-4)`，攻击倍率 `1.03^(n-4)`，相邻档位分别乘 1.05、1.03；生命按生成时取整。仅修改生命和伤害，不改刷新频率、移速、经验、金币或掉率。

| 难度 | 敌人生命 | 敌人攻击 |
|---|---:|---:|
| 1★ | ×0.864 | ×0.915 |
| 2★ | ×0.907 | ×0.943 |
| 3★ | ×0.952 | ×0.971 |
| 4★ | ×1.000 | ×1.000 |
| 5★ | ×1.050 | ×1.030 |
| 6★ | ×1.103 | ×1.061 |
| 7★ | ×1.158 | ×1.093 |
| 8★ | ×1.216 | ×1.126 |

普通敌人、普通首领、裂缝与 Mega 首领、最终审判召唤首领、召唤物均由统一生成入口计算一次。远程攻击和预警技能沿用攻击倍率；阿尔宙斯的百分比攻击也乘攻击倍率，其原有无敌设定保留。联机复制的敌人直接使用房主数值，不再叠乘。

正常游戏时间**严格超过 20:00 且角色存活**时立即保存通关并提示，继续生存可刷新纪录，不强制结束。暂停、升级选卡、审判过场不增加生存时间。新局难度固定，不能局中换星。调试/跳时等不发奖、不刷新难度纪录。

每只本体宝可梦独立拥有八枚对应星级奖牌，普通/异色与 Mega 形态共用本体纪录：

- 任意难度第一次胜利：金色边框。
- 获得五星奖牌：绿宝石边框。
- 集齐一至八星全部奖牌：红宝石边框；只通关八星不等于集齐八枚。

边框显示于主菜单伙伴、图鉴格子与详情大图；闪光标记保留。图鉴详情展示八枚奖牌，各奖牌悬停可查看该星级时间，并展示该宝可梦挑战过的最高星级及该星级最长生存时间（包括该难度尚未通关的尝试）。最终结算更新本局完整时间，低难度更长的时间不会覆盖高难度纪录。

联机由房主所选难度与所有成员已解锁上限共同决定，取最小值，开始时同步给所有成员。旧客户端成员缺少解锁信息时按一星处理；每位玩家为自己使用的本体记录奖牌，不能通过伪造高难度跳关。

## 挂机收益

仅已注册的本地账号与云账号可获取，游客不能获取。首次进入仅开始计时，不追溯旧时间。退出账号、关闭页面或切到后台后按现实时间累积，返回自动结算；前台活动不累积。前台每 30 秒本地记录活跃时间，正常退出/隐藏页面时立即记录，异常退出可能有最多约 30 秒误差。无离线时长上限。

设 N 为游戏本体图鉴总数（当前 966），D 为点亮普通图鉴数，S 为闪光图鉴数（按物种去重，不含独立 Mega 物种）：

```text
收集进度 p = min(1, (D + 10S) / (11N))
金币每小时 = 100 + 4900 × sqrt(p)
单抽券每小时期望 = 1 + 4 × sqrt(S/N)
特性宝石每小时期望 = 0.5 + 1.5 × sqrt(S/N)
```

金币前期增长快、后期增量变缓；普通和闪光分别贡献权重 1、10。零收藏时为 100 币、1 张单抽券期望、0.5 枚宝石期望／小时；普通与闪光都满时精确达到 5000 币、5 张券期望、2 枚宝石期望／小时。不是每小时保底发券或发宝石。

金币按实际离线时长线性累积，小数保存在存档中，下次继续累加。单抽券和宝石以泊松过程采样，平均值为小时产出率乘离线小时数。离线阶段使用离开时保存的产出率，返回后的新收藏产出率从此后生效；余额、单抽券、特性宝石直接入账，在主菜单「挂机收益」查看当前产出与本次结算。

结算游标与奖励同时保存；同一浏览器以 Web Locks（浏览器支持时）串行结算，云账号通过 Firestore 事务串行处理重叠区间。累计已结算收益帮助合并较新但尚未见过奖励的旧客户端，避免奖励丢失或重复合并。云端结算失败不先发本地奖励、不推进游标，联网后重试；旧存档无此字段时从当前时刻起算。系统使用客户端现实时间，回拨不会重领，服务器权威时钟校验尚未接入。

## 一倍速与二倍速

暂停菜单「游戏速度」按钮或 V 键切换 1×／2×，每局默认 1×。这是正式功能，不会将本局标记成调试。战斗、移动、冷却、天气、裂缝、Mega 和生存计时一起加速；每帧执行两次正常物理步长，避免直接把单步加大而跨过碰撞。任一步打开选卡等暂停流程时停止后续步，不额外推进。

二倍速下，20 分钟游戏时间约需 10 分钟实际游玩，正常获得难度奖牌；挂机始终按现实时间计算。联机只有房主能修改，队友跟随房主快照，速度不可各自设置。

原云排行榜的服务端规则用现实时间校验，且尚无难度分榜，所以本版本仅四星、全程一倍速、无调试的正常局参与原榜。二倍速或其他星级的通关奖牌、图鉴纪录与正常游戏收益仍保存，结算页说明原榜条件；没有部署或放宽生产服务规则。

## 存档与验证

存档 v6 新增 `difficulty`、`difficultyRecords`、`offline`。云合并保留奖牌与逐星最长纪录；重复合并不会重复发奖或加币。游戏源码仍为 dev.html，正式构建同时为脚本和 CSS 加上内容版本，CSS 变化也触发更新，避免旧缓存使难度选择与宝石边框失去样式。

测试命令：`node --test tools/test_abilities.cjs tools/test_mega_preview.cjs tools/test_mega_evolution.cjs tools/test_levelup.cjs tools/test_difficulty.cjs tools/test_offline.cjs`。

本地网页验证包括注册测试账号实际离线结算、选择器锁定、暂停按钮与 V 键切换、图鉴详情。三档边框另外用真实 UI 组件与独立内存夹具预览，没有伪造正式账号通关。20 分钟边界、双倍速计时资格、多人结算和并发事务采用自动测试；尚未进行真实双设备联网试玩，也未连续实玩二倍速完整十分钟。

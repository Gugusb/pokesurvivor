# 进化方向

普通升级奖励照常选择。达到进化阶段时，再额外打开“进化方向”界面；只抽永久属性，不抽普通技能、超武或即时回血道具。选定方向后才执行进化。

- 第一段进化在 6 级，后续阶段在 15 级，沿用当前等级规则。
- 单一方向：三张不同属性供选择，均进化到同一形态。
- 两个方向：各显示一张卡。超过三个方向：随机展示至多三个不同分支，每个分支对应一张属性卡。
- 分支随机范围来自完整的进化树，不受进局前选中图鉴形态的固定路线限制；选择后，后续进化只能沿已选路线继续。
- 重抽仍然抽进化方向，不会换回普通技能卡。它消耗同一局原有的重抽次数。
- 进化卡不改变普通升级“连续两次至少有一个已学技能升级”的抽取记录。进化奖励不触发新的等级增长、慢启动额外选择或普通污染卡抽取。

| 永久属性 | 普通收益 | 进化收益 |
|---|---:|---:|
| 生命上限并恢复等量生命 | +20 | +60 |
| 攻击倍率 | +10% | +30% |
| 移动速度 | ×1.07 | ×1.21 |
| 技能冷却时间 | ×0.92 | ×0.76 |
| 减伤比例 | +6% | +18% |
| 每秒恢复生命 | +0.9 | +2.7 |
| 经验拾取半径 | ×1.30 | ×1.90 |
| 获得经验 | ×1.12 | ×1.36 |

“三倍”指本次百分比或平坦增量为普通选择的三倍，非将最终属性直接乘三。一次计作三层对应属性；不能提供完整三倍收益的封顶属性不进入该次抽取。极端情况下剩余永久属性少于卡片数量，可重复提供仍有效的属性以保留分支选择。

进化保留已获得的生命上限加成、血量比例、技能、Z 充能及其他永久收益；按新形态的个体值重新计算种族基础生命/攻击/移速，更新属性、外观和已装备的特性。进化不会额外回满血。联机时每个玩家分别选择，全部选择完成后继续战斗。

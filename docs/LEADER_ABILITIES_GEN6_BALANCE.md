# 第六世代队长特性：实施前收益估算与试玩调整

基线 v0.43.0-alpha.63（8ce2a8e）。以下37项在本轮运行实现前逐项估算；不将静态估算作为实战DPS。源文SHA256：e4a528cc443e60176ed9bb4c8cfe871a13f9597b157cef8abc950f75aff499a1。

等双攻时，单独物攻提升x使物理技能约提升0.65x，特殊技能约提升0.35x；实际仍使用该形态双攻。普通会心1.5倍，额外会心p令期望伤害×(1+0.5p)。物理有效生命≈生命×物防/额外承伤。Z按budget单位估算，预算分配不是每个多段各得一份。下列有效生命比较仅统计特性提供的额外乘区，实际还需加入原生克制并按第六世代0.3—2.4钳制。

- 以alpha.63为基线；原文逐段保留，下面单列试玩修正。基础与代价开局生效，训练家5/8级进阶，家族勋章解锁手动Z，匹配行为约60游戏秒充满、最多一发、跨战保留。
- 按确认：补给生成就计充能，治疗和PP胜利后发放给击杀者，加速留给下一战；试玩上限为每场果实4份、根茎2份。
- 按确认：受预算限制的Z治疗排队以每秒3%最大生命逐步兑现；多种治疗共用预算，补偿不产生再次排队或递归充能。
- 按确认：哲尔尼亚斯群救援每场一次，队长与阵亡队员25%血，存活成员至少25%且不降血；黏黏宝基础近战实际受伤可充能。
- 按确认：属性倍率0.3—2.4仅限第六世代，0倍免疫保留；复合攻击均分威力逐属性结算。主技能物特65/35，防御展示值按100×基础系数换算。
- Z输出锚定当前主招10秒理论伤害budget；同次多个弹体/往返/反射对同一精英或首领合计不超过65%预算，单命中不超过30%，BOSS控制时长减半。

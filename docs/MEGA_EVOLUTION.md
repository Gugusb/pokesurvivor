# Mega 进化系统

版本 v0.8.0，2026-10-16。

## 获取和装备

- 正式开放 36 个基本动作达标形态；完整形态清单见 [MEGA_CATALOG.md](MEGA_CATALOG.md)。原有 4 个部分完成素材仍仅供开发预览。
- 每次正常进入裂缝，20% 概率改为 Mega 首领，36 个形态等概率，各占全部裂缝的 1/180。其余 80% 沿用原有传说首领选择规则。
- 击败 Mega 首领时独立判定 5% 概率掉落对应进化石，自动收入永久收藏；并非普通首领也能掉。单次裂缝掉任意 Mega 石的总概率为 1%。重复获得仅提示已拥有，不叠加、不返还货币。
- 在主菜单 → 宝可梦 → 对应本体详情的「Mega 进化石」栏目装备或卸下。石头永久、不消耗，只能给对应本体使用；开局固定本局装备，局中不能换石。特性勋章仍可同时装备。
- 携带 Mega 石时，以 Mega 按钮替代普通道具栏，充能中、变身中、变身结束后始终不显示普通道具栏，也不能装备普通道具。拾取普通道具立即转为当前等级基础升级需求的 25%（向下取整，至少 1），再应用经验倍率；不弹选择框。联机由房主为全队增加共享经验一次，无石玩家继续正常装备普通道具。
- 联机由房主选择首领和判定一次掉落，全队获得同一结果，各自永久收藏；重复胜利消息不重复发奖。原有裂缝特性宝石、金币、抽奖券和融合奖励继续保留。

## 充能和变身

- 新局能量为 0，上限 120；自然每个有效游戏秒 +1；自己的每次击杀额外 +0.1，额外速率最高每秒 +0.25（容量 0.25 的恢复预算），不因队友击杀重复获取。
- 满能量后按 F 或点击技能栏最左侧的 Mega 石按钮，消耗全部能量，变身 60 秒；变身期间自然充能和击杀充能都暂停，结束从 0 开始。首次自然蓄满 2 分钟；之后 1 分钟变身加 2 分钟自然充能，基础循环 3 分钟。击杀会适度缩短蓄能时间，理论最快约 96 秒充满。
- 暂停、选卡等不推进游戏时间时不充能、不消耗持续时间；倒下不能充能或主动变身，倒下会结束变身。新局、退出后不保留能量。
- 变身及还原保持当前生命比例，不额外治疗：当时未变身生命上限 ×1.3，伤害 ×1.5，最终承伤 ÷1.3。局内新增生命上限也受倍率影响，还原时保留原始升级数值。减伤与已有防御、特性效果叠乘。
- 变身时击退半径 180 世界单位内的所有存活敌人，包含首领，初始击退速度 480、按现有摩擦衰减，理想位移约 74 世界单位，墙壁与裂缝边界仍限制位移；不造成额外伤害。
- 不替换特性勋章、不改变技能栏/技能等级/技能自身进化；按原版 Mega 形态改变类型。碰撞半径沿用本体，外观及地面阴影使用 Mega 素材；异色素材缺失时使用普通 Mega 外观。

## 技能强化

所有输出技能统一享受 ×1.5 伤害，以下是在其基础上的专属强化。

| 类型 | Mega 期间额外强化 |
|---|---|
| 增益 buff | 每次叠加的有效层数和有效上限均翻倍，已有层数也翻倍；持续时间不变，还原时恢复原层数规则 |
| 投射物 projectile | 穿透 +3，子弹半径与视觉尺寸 ×1.3 |
| 近战 melee | 冷却推进速度 ×1.5（等效冷却 ÷1.5），兼容精神力的后台冷却 |
| 能量柱 beam | 宽度 ×2，命中判定同步扩大 |
| 陨石 meteor | 每次落下数量 ×2 |
| 回旋 boomerang | 沿用投射物尺寸与穿透强化；原本已经能无限穿透，因此不会削弱它的原有穿透规则 |
| 连锁 chain | 连锁最大目标数量 ×2，保留每跳衰减 |
| 环绕 orbit | 半径 ×1.3，旋转角速度 ×2，不改变单目标重复命中间隔 |
| 冲击波 nova | 径向弹丸存活时间 ×1.3，等效最大扩散半径 +30%，保持弹速 |
| 持续光环 aura | 作用半径 ×1.3 |
| 地雷 mine | 爆炸半径 ×1.3，触发半径与布置数量不变 |
| 炮台 turret | 发射间隔减半，即射速 ×2，炮台数量和寿命不变 |
| 冲刺 dash | 冲刺结束后 0.6 秒获得额外 70% 减伤；与原有 0.3 秒无敌并行计时，重复冲刺刷新不叠加 |
| 地面轨迹 trail | 额外伤害 ×1.4，与统一倍率合计 ×2.1 |
| 扇形 cone | 冷却缩短 25%，等效持续输出约 ×2（含统一伤害倍率） |

强化在施法时生成临时参数，不改写已学技能，兼容技能升级、融合和技能自身进化。还原后新施法使用普通参数；已发射子弹、已布置场地继续使用施法时的尺寸/数量等参数，统一伤害倍率按命中时状态结算。持续环绕参数随当前状态更新。

Mega 技能保留原招式形状，换用粉紫—青白调色板与发光轨迹，施法粒子按每人 180ms 限频，并沿用画质档位的粒子总量上限。颜色变化仅影响视觉，不改变招式伤害属性。

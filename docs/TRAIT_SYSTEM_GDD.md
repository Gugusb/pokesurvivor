# 远征宝可梦特性系统 · 首轮实现

来源：提供的Trait System GDD及后续确认。v0.43.0-alpha.10 接入首轮可玩系统，仅用于Next远征队员；v0.43.0-alpha.11 起品质改用独立的[远征品质](EXPEDITION_QUALITY.md)，不再采用旧抽卡rarity；完整30项目录及966物种分配见 [TRAIT_CATALOG.md](TRAIT_CATALOG.md)。

## 定位

羁绊负责以不同宝可梦的属性、蛋组和职业凑齐阈值；特性负责产生羁绊层数、推动局内经济，并把层数转化为个体战斗收益。特性池设计及分配比例为叠层50%、经济30%、终端20%。

- 叠层：只作用于特性持有者自身参与且已激活的标签；多标签按特性说明分别增加，不给尚未激活的标签预存收益。
- 经济：作用于局内金币、招募、刷新、放生及道具，不直接等同于账号宝可梦币。
- 终端：不直接产层，用已激活羁绊的有效层数产生战斗增益。

## 统一权重

最终收益 = 收益底数 × 星级权重 × 品质权重。

| 阶级 | 星级权重 |
| --- | ---: |
| 1阶 | 1.0 |
| 2阶 | 2.0 |
| 3阶 | 3.0 |

| 品质 | 品质权重 |
| --- | ---: |
| 1 普通 | 1.0 |
| 2 优良 | 1.2 |
| 3 稀有 | 1.5 |
| 4 史诗 | 2.0 |
| 5 最高品质（神兽/幻兽固定） | 2.5 |

3阶4品的总权重为6.0。

### 终端转化

战斗增益 = 已激活羁绊有效层数 × K_base × 星级权重 × 品质权重。

| 方向 | K_base | 16层、3阶4品的结果 |
| --- | --- | --- |
| 独立最终增伤 | 每层+0.8% | +76.8% |
| 冷却缩减 | 每层+0.5%，总上限40% | 48%，封顶40% |
| 斩杀生命线 | 每层0.4% | 38.4% |
| 技能范围/判定/特效 | 每层+0.6% | +57.6% |
| 战斗开始白盾 | 每层5%基础生命 | 480%基础生命 |

## 已确认规则及首轮边界

1. 新特性替换旧队员按首属性给予的全队支援；队长原特性勋章保持原规则。所有新特性要求持有者上阵且存活，候补及倒下者不产出、不享受终端收益。羁绊凑数仍沿用原规则，倒下不移除标签贡献。
2. 品质仅1—5档；每只队员一个固定家族特性，进化及合成保留该特性。合成后后续事件立即采用新阶级、当前形态品质，不补发过往收益。队长不获得队员特性。
3. 层数保留6位小数，单标签上限10000。金币小数累计至本局共享余数后发整金币；同一日的多个利息持有者均以事件触发前的钱包为基数，不按编队顺序互相复利。
4. 目前只接入有激活规则的18属性（2/5名）和投射物/近战/能量柱/环绕/连锁5职业（3/6名）。蛋组及其余职业尚无效果与阈值，不作为特性的叠层目标或终端燃料。多属性、同职业去重，只计算自己参与的已激活标签；职业默认1层沿用，属性默认0层。
5. 精英T4为事件成功通关一次（包括坚持到时限），要求持有者在结算前存活；普通全歼要求时限内清理完毕；周期BOSS要求击败首领。结算在战后恢复前进行。日终在完成当天事件时发放；访问商店每个日程只触发一次。重复结算与刷新页面不重复发奖。
6. 命中/暴击/击杀统计仅在战斗阶段；命中与暴击只计自己的招式实际造成生命或护盾损失，不计羁绊生成的二次伤害、装备伤害及无效命中。受击按实际生命损失计数，白盾全吸收、闪避、免疫、天气/环境伤害不计。放生奖励发给其他仍上阵且存活的特性持有者，离开的本人不领取自己的放生奖励。
7. 终端燃料为自身参与的所有已激活标签层数之和，乘总权重。独立增伤加在自身招式最终倍率；冷却缩减最高40%，不改变PP规则；范围判定和预览同步，额外范围首轮上限+300%。斩杀线首轮上限50%，普通敌人低于线时可直接处决；精英、BOSS及传说敌人不直接处决，在血线内改为额外乘以1+斩杀线。
8. 开战白盾以持有者当前形态基础生命（含个体修正、不含本局生命成长）为基数，按公式重置。先计算既有防御/免伤，再吸收；溢出的剩余伤害进入原生命和濒死判定。白盾不跨战斗叠加、不因战斗中涨层自动补充，场上显示白色护盾轮廓和剩余数值。
9. 特性独立增伤和处决伤害在原账本中分列为“某特性伤害”，按实际生命/护盾损失守恒拆分，排除过量；冷却和范围带来的间接收益仍计入宝可梦伤害。原羁绊伤害分类保留。
10. 免费刷新优先于金币使用，保留商品锁；定向招募券可在商店选择一个正在出售的宝可梦免费邀请，保留商品阶级及固定技能，不用于道具。满仓或失败不会消耗，成功后售罄；资源跨日保留至本局结束。议价按每位持有者8%×总权重加算，全队最高50%，最低价格1金币，只影响宝可梦招募。
11. 目录15/9/6严格满足5:3:2；按509条家族分配后的实际数量255/153/101，按966物种为502/285/179，保留进化链一致优先。分配算法和全表可复核；首轮尚未逐家族按生态故事调优。全部状态仅在本局内，不新增账号存档字段，不处理关闭战场后的恢复。

上述上限、精英/BOSS处决替代、折扣及第30项攻守混合特性属于授权自主设计的首轮试玩平衡，后续依据实际长局体验调整。

## 验证目标

- 只给自身拥有且已激活的标签加层，所有作用范围与双标签去重有独立验证。
- 各阶级、品质及小数收益满足权重公式；合成后立即使用新星级，不回溯重发历史产出。
- 击杀、全歼、日终、商店、放生、合成与BOSS事件不得被返回页面或重复结算反复触发。
- 候补、倒下与存活条件按特性描述区分；不得在阶段恢复后反算“自身存活”。
- 金币、次数资源、优惠与队伍变更相互隔离，验证买入/放生/免费刷新组合的实际扣款与发奖。
- 终端伤害、冷却、真实判定范围与显示一致，白盾吸收与真实受伤触发分别验证，保留原伤害统计和队长勋章边界。
- 沿用隔离账号/SQLite、三语PC/手机及标准构建无开发模块的发布验证。
